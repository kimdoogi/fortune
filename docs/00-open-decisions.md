# 00. 먼저 정할 결정

확정되면 [결정 기록](decisions/README.md)으로 옮기고 이 표에서 지운다.

## 확정된 것 (요약)
- 웹 · three.js 직접 (3D는 런타임 코드 생성) · Preact (2D UI) · 2D 에셋은 코드로 만든 SVG
- 2등신 캐릭터 (4나이대 × 성별 = 8종), Codex CLI로 제작
- MVP 점집 4개: 사주 (표준시 + 서머타임 보정), 타로, 아기도령 (오방기 뽑기), 꿈해몽 (자유 서술 300자, Haiku가 상징 추출)
- 마을은 멀티플레이 (채널 30명, 정해진 문장 + 이모트) / 점집 내부는 개인 공간
- **Cloudflare만 사용:** app Worker (Static Assets + API) · reading Worker (LLM 전용, 공개 주소 없음) · AI Gateway · Durable Objects · D1 · KV
- Haiku 5.5 전용, LLM은 해석과 말투 (+ 꿈 상징 추출)
- **MVP는 완전 무료: 결제도 복채도 없다** (D-057). 비용은 사용자당 하루 LLM 30회 상한과 IP당 계정 생성 제한으로 막는다. 자유질문 100자, 꿈 300자. 비회원만
- 만 14세 미만 이용 차단

## 남은 결정

큰 결정은 모두 끝났다. 남은 것은 각 문서의 ⬜ 항목이고, 대부분 **채워 넣을 콘텐츠**다.
