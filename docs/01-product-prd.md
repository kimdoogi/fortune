# 01. 제품 기획 (PRD)

상태: 🟡 초안

## 한 줄 요약
2등신 캐릭터로 점집 마을을 돌아다니며 다른 사람들과 어울리고, 점집에 들어가면 나만을 위한 공간에서 사주·타로·신점을 보는 모바일 웹 메타버스.

## 타깃
- 플랫폼: ✅ 모바일 웹 (세로 화면 기준 ⬜)
- 주 사용자: ⬜ (가정: 운세 앱을 쓰는 2030)
- 사용 상황: ⬜ (예: 출퇴근길 짧은 세션, 자기 전)

## 핵심 루프
1. (첫 방문) 프로필 입력 (닉네임, 생년월일, 태어난 시간(모름 가능), 성별) → 2등신 캐릭터 생성 (D-046)
2. 지도에서 점집 선택
3. 그 점집의 거리에서 걸어 다니기 (다른 유저와 함께, D-047)
4. 점집 건물에 들어가면 개인 공간으로 화면 전환
5. 점 보기 (MVP는 모두 무료, D-057)
6. 결과 저장·공유 → 다음 날 일일운세로 재방문

## MVP 점집 (✅ 5개)

| # | 점집 | 코드가 하는 일 | LLM이 하는 일 | 상태 |
|---|---|---|---|---|
| 1 | 사주집 | 만세력 계산, 오행·십신 등 | 해석 + 말투 | ✅ |
| 2 | 타로집 | 카드 뽑기, 정/역방향 | 해석 + 말투 | ✅ |
| 3 | 아기도령 (신점) | 오방기 뽑기 (D-031) | 해석 + 반말 아이 말투 | ✅ |
| 4 | 꿈해몽 (D-009) | 꿈 사전에서 상징 의미 조회 | 상징 추출 (D-028) + 해석 + 말투 | ✅ |
| 5 | 족집게집 (D-100) | 사주 원국 계산, 십신 무리 세기, 기질 장면 표 조회 | 해석 + 하게체 말투 | ✅ |

## 요금 (D-057)

**MVP는 완전 무료다.** 결제도 복채(게임 화폐)도 없다. 모든 점을 무료로 볼 수 있다.

- LLM 비용과 악용은 **사용자당 하루 LLM 호출 30회 상한**과 **IP당 하루 계정 생성 5개** 제한으로 막는다 ([F14](features/F14-session.md))
- 같은 조건의 점은 결과가 고정·저장되어 다시 봐도 LLM을 부르지 않는다
- 유료화(복채, 잠금 섹션, PG)는 출시 후 M6에서 [10-payments-currency.md](10-payments-currency.md)와 [F12](features/F12-coins.md) 설계로 시작한다

## MVP에서 하지 않는 것
- 실제 상담가 연결
- 네이티브 앱 출시
- 브랜드 콜라보 점집
- 결제(PG)와 복채 — 출시 후 추가 (D-057)
- 로그인 — 비회원만 (D-015)
- 자유 채팅 — 정해진 문장 + 이모트만 (D-010)
