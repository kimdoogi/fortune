## 2. 기둥 세우는 규칙
- ✅ 연주: 입춘 시각을 지나야 해가 바뀐다. 간지 = 60갑자에서 (연도 − 4) mod 60
- ✅ 월주: 12절 시각을 지나야 달이 바뀐다 (입춘→인월, 경칩→묘월 … 소한→축월). 천간은 월두법: 갑·기년 병인, 을·경년 무인, 병·신년 경인, 정·임년 임인, 무·계년 갑인부터
- ✅ 일주: 날짜의 60갑자 순환. 율리우스일 기준 (JDN + 49) mod 60 (갑자 = 0). KASI 일진 218일치와 일치 확인
- ✅ 시주: 기준시의 시(§3) + 시두법: 갑·기일 갑자, 을·경일 병자, 병·신일 무자, 정·임일 경자, 무·계일 임자부터
- ✅ 자시 처리: 야자시를 구분하지 않는다 (D-032, D-033)
- ✅ **절기 시각은 엔진에 넣는 표에서 찾는다 (D-039).** 아래 §2-1

### 2-1. 절기 시각 표 (D-039)
- 1920~2050년 **24절기** 시각 표를 미리 만들어 `packages/fortune-engine/data/solar-terms.json`에 넣는다. UTC 분 단위, 약 30KB
- 만드는 방법: 정밀 천문 계산(지구 중심 겉보기 황경, KASI와 같은 정의)으로 생성하는 스크립트를 `tools/solar-terms/`에 둔다. 계산은 **Python Skyfield + NASA JPL DE440s 천체력**으로 한다 (개발 도구로만 쓰고, 엔진에는 결과 JSON만 들어간다)
- ✅ **생성 완료 (2026-11-24):** 1919~2051년 133년치, 37KB. 계산값이 KASI 발표값보다 평균 7초 늦게 나와서 **7초를 빼고 분 단위로 반올림**한 뒤, KASI 공식 시각이 있는 곳은 KASI 값으로 덮어쓴다 (D-062)
- ✅ 대조 결과: KASI 2004~2017년 12절 168개 중 161개가 보정 계산만으로 같은 분, 나머지 7개는 1분 차이(초가 :30 경계 근처)라 KASI 값으로 덮어썼다. KASI 공개 자료가 없는 해는 최대 1분 차이가 날 수 있다
- [ ] KASI 2004~2017년 중기 12개, 2021년 이후 24기도 받아서 덮어쓰기·대조 범위를 넓힌다
- **검증:** 생성한 표가 KASI가 공개한 시각과 분 단위로 전부 일치해야 한다. 다르면 KASI 값을 쓰고 차이를 `overrides`에 기록한다. 2018~2020년은 웹 공개 자료가 없어 대조하지 않는다
- 이 검증으로 02a의 "2004년 이전 절기 경계는 테스트 못 함" 빈틈을 줄인다 (같은 계산 방법이 공식 시각과 맞는다는 근거)
- 엔진은 실행 중에 천문 계산을 하지 않는다

## 3. 시간 보정
- ✅ 표준시 + 서머타임만 보정한다. 진태양시 보정은 하지 않는다 (D-032)
- ✅ **기준시**: 출생 시계 시각에서 그 시기 표준시·서머타임을 빼 UTC로 바꾼 뒤 **UTC+8:30**으로 환산한다. 시 경계는 기준시 정시 홀수시이고, 지금 한국 표준시로는 23:30, 01:30, 03:30 …이다 (D-034)
- ✅ 일주는 자시가 시작되는 기준시 23:00(지금 한국 표준시 23:30)에 다음 날로 넘어간다 (D-033)
- ✅ 서머타임·표준시 이력: IANA tz database `Asia/Seoul` (D-062, [02a §3](02a-saju-test-cases.md#3-표준시--서머타임-이력-d-062))
- ✅ 안내 문구 (사주판 아래): "한국 표준시 기준으로 본 사주예요. 다른 만세력과 태어난 시(시주)가 다르게 나올 수 있어요."

## 4. "시간 모름" 처리
- ✅ 연·월·일 삼주만으로 계산한다
- ✅ 시주에 의존하는 항목은 결과에서 뺀다: 시주의 십신, 신강 점수의 시간·시지
- ✅ 화면과 LLM 입력에 `hourUnknown: true` 표시
- ✅ 절기 당일에 태어났으면 정오 기준으로 계산하고 `solarTermDay: true`로 표시한다 (D-036)
- ✅ 대운수 계산에도 정오를 쓰고, 결과에 "대운 시작 나이는 ±1년 달라질 수 있음"을 표시한다

## 4-1. 서머타임 전환 시각 입력

- 지장간의 중기·여기는 MVP에서 쓰지 않는다

### 5-1. 오행 분포
- 천간 4개 + 지지 4개(본기 오행)를 오행별로 센다. 합계 8 (시간 모름이면 6)
- 출력 예: `{ "목": 3, "화": 2, "토": 1, "금": 1, "수": 1 }`
- 0개인 오행은 `missing`, 3개 이상은 `excess`로 표시한다

### 5-2. 십신
일간을 기준으로 다른 7글자(시간 모름이면 5글자)마다 붙인다. 지지는 본기로 판단한다.

| 관계 (일간 기준) | 음양 같음 | 음양 다름 |
|---|---|---|
| 같은 오행 | 비견 | 겁재 |
| 일간이 생함 | 식신 | 상관 |
| 일간이 극함 | 편재 | 정재 |
| 일간을 극함 | 편관 | 정관 |
| 일간을 생함 | 편인 | 정인 |

- 무리: 비겁(비견·겁재), 식상(식신·상관), 재성(편재·정재), 관성(편관·정관), 인성(편인·정인)

### 5-3. 신강·신약 (D-041 ✅)
일간을 돕는 글자(비겁 + 인성)의 힘이 전체에서 차지하는 비율로 판정한다.

| 자리 | 가중치 |
|---|---|
| 월지 (월령) | 3 |
| 일지 | 1.5 |
| 연간, 월간, 시간, 연지, 시지 | 각 1 |
| 일간 자신 | 계산에서 뺌 |

- 돕는 점수 = 비겁·인성인 자리의 가중치 합
- 전체 점수 = 일간을 뺀 모든 자리의 가중치 합 (기본 9.5, 시간 모름이면 7.5)
- 비율 = 돕는 점수 ÷ 전체 점수
- **신강** 비율 ≥ 0.55 / **신약** 비율 ≤ 0.45 / 그 사이는 **중화**
- 출력: `{ "label": "신강", "ratio": 0.63 }`

### 5-4. 용신·희신 (D-041 ✅, 억부 방식)
조후(계절) 보정은 MVP에서 하지 않는다. 오행별 점수 = 그 오행에 해당하는 자리 가중치 합(§5-3 가중치)으로 비교한다.

| 판정 | 용신 | 희신 |
|---|---|---|
| 신약 | 인성 오행 | 비겁 오행 |
| 신강, 인성 점수 > 비겁 점수 | 재성 오행 (인성을 누름) | 식상 오행 |
| 신강, 그 외 (비겁이 강함) | 관성 오행. 관성 점수가 0이면 식상 오행 | 재성 오행 |
| 중화 | 점수가 가장 낮은 오행 (동점이면 목→화→토→금→수 순서) | 용신을 생하는 오행 |

- 출력: `{ "yongsin": "수", "huisin": "금", "method": "억부" }`
- 이 규칙은 **우리 서비스의 기준**이다. 다른 만세력·역술가와 결론이 다를 수 있으므로 화면에 "이 풀이의 기준"이라고만 표현한다

### 5-5. 대운
- **방향:** 양년생(연간이 갑·병·무·경·임) 남자, 음년생 여자 → 순행. 음년생 남자, 양년생 여자 → 역행
- **대운수:** 순행이면 출생 시각부터 다음 절까지, 역행이면 직전 절부터 출생 시각까지의 일수(소수 포함)를 3으로 나누고 반올림. 최소 1, 최대 10 (반올림 방식은 유파마다 다르며, 이 서비스는 일반 반올림을 쓴다)
- **기둥:** 월주에서 순행이면 다음 간지, 역행이면 이전 간지로 한 칸씩. 10개(100년치)
- **나이:** 대운 시작 나이 = 대운수 (만 나이). 이후 10년마다 다음 대운
- **현재 대운:** 오늘 날짜 기준으로 해당하는 대운을 `current: true`로 표시

### 5-6. 세운 · 월운 · 일진
- **세운:** 해당 연도의 연주 (입춘 기준). 신년운세는 다음 해 입춘부터의 간지를 쓴다
- **월운:** 해당 월의 월주 (절기 기준)
- **일진:** 해당 날짜의 일주. 오늘의 운세는 한국 표준시 날짜 기준
- 각 운의 천간·지지에도 원국 일간 기준 십신을 붙인다

### 5-6-1. 앞으로 12달 월운 등급 (D-079)
사주 정밀에서 "몇 월에 뭘 조심하고 몇 월이 좋은지"를 말하기 위해 **코드가 달마다 점수를 매기고 좋은 달·조심할 달을 고른다.** LLM은 고른 달만 풀어 준다.
- **기간:** 풀이를 본 달부터 12달. 각 달은 양력 그 달 15일(서울 정오)의 월주로 대표한다 (절기 달은 그 달 4~8일쯤 바뀌므로 15일은 늘 그 달에 시작한 절기 달 안에 있다)
- **기신:** 용신을 극하는 오행 (목→토, 화→금, 토→수, 금→목, 수→화 관계에서 용신을 극하는 쪽)
- **점수:** 월주 천간과 지지 각각 — 용신 +2, 희신 +1, 기신 −2. 그리고 월운과 원국의 합충([5-7](#5-7-합충-mvp-범위)) — 일지·일간과의 충 −2, 다른 자리와의 충 −1, 일지·일간과의 합 +1
- **고르기:** 점수 높은 순(같으면 이른 달)으로 **좋은 달 2~3개**(점수 1 이상인 달 최대 3개, 모자라면 위에서부터 2개까지 채움), 점수 낮은 순으로 **조심할 달 2~3개**(−1 이하 최대 3개, 모자라면 아래에서부터 2개까지 채움). 나머지는 보통
- **각 달에 붙이는 사실:** 월운 간지, 십신(천간·지지), 등급의 이유(용신이 들어옴 / 기신이 들어옴 / 어느 자리와 충), 십신별 생활 기회·조심 키워드([7](#7-해석-데이터-테이블)), 충이면 자리별 뜻(일지 = 연인·배우자·가족, 월지 = 직장·사는 곳, 연지 = 부모·윗사람, 시지 = 자녀·후배·계획)
- 12달이 입춘을 넘으면 다음 해 세운도 사실로 같이 넣는다

### 5-6-2. 오늘의 운세 점수·행운의 숫자 (D-080)
오늘의 운세는 일간 × 일진으로만 정해진다 ([F13](features/F13-daily.md)). 점수와 숫자도 코드가 정한다.
- **점수 (40~99):** 70에서 시작. 일진 천간·지지의 십신마다 더한다 — 식신·정재 +6, 정관·정인 +5, 편재 +4, 비견 +2, 편인 0, 상관 −2, 겁재 −3, 편관 −4. 일진 천간이 일간과 합이면 +6, 충이면 −8. 마지막으로 날짜·일간으로 정해지는 −5~+5를 더한다 (같은 날 같은 일간이면 같은 점수)
- **등급:** 85 이상 "아주 좋음", 70 이상 "좋음", 55 이상 "보통", 그 아래 "조심"
- **행운의 숫자:** 행운의 색과 같은 오행(일간을 생하는 오행)의 하도수 두 개 — 수 1·6, 화 2·7, 목 3·8, 금 4·9, 토 5·10
- 점수·등급·숫자를 `facts`에도 넣어 풀이 말투가 점수와 어긋나지 않게 한다

### 5-7. 합충 (MVP 범위)
원국끼리, 그리고 운(대운·세운·월운·일진)과 원국 사이에서 찾는다.

| 종류 | 목록 |
|---|---|
| 천간합 | 갑기, 을경, 병신, 정임, 무계 |
| 천간충 | 갑경, 을신, 병임, 정계 |
| 지지 육합 | 자축, 인해, 묘술, 진유, 사신, 오미 |
| 지지 육충 | 자오, 축미, 인신, 묘유, 진술, 사해 |

- 삼합·방합·형·파·해는 MVP 이후
- 출력 예: `{ "type": "지지육충", "a": "세운 지지 오", "b": "일지 자" }`

## 6. LLM에 넘길 데이터 형식
계산 결과를 [04-llm-spec.md](04-llm-spec.md#2-입력-형식-코드--llm)의 입력 JSON으로 변환한다. LLM이 추론하지 않도록 **해석에 필요한 사실은 모두 코드가 채운다** (예: "일간 갑목, 신강, 용신 수").

## 7. 해석 데이터 테이블
LLM에 넘기기 전 코드가 붙이는 기본 의미. **우리가 직접 쓴다**: 명리 일반론을 바탕으로 AI로 초안을 만들고 사람이 검수한다. 특정 책·사이트의 문장을 그대로 옮기지 않는다. 파일은 `packages/fortune-engine/data/meanings/`
- [ ] 일간 10개별 성향 키워드
- [ ] 십신 10개별 의미 (원국에 있을 때 / 운으로 올 때)
- [ ] 오행 과다·부족 의미
- [ ] 신강·신약·중화 의미
- [ ] 용신 오행별 조언 키워드 (색, 방향, 활동 등)
- [ ] 합충 종류별 의미
- [ ] 십신별 생활 기회·조심 키워드 (운으로 올 때, 월별 풀이용, D-079)
- [ ] 충이 닿는 자리별 뜻 (일지·월지·연지·시지, D-079)
