# 03. 타로 · 기타 점 규칙

상태: ⬜ 미정

## 공통: 결과 고정 규칙
- ✅ 같은 사람이 같은 날 같은 점을 보면 같은 결과가 나온다
- ✅ seed는 상품마다 다르다: 사주 정밀은 프로필 버전 + 연도, 타로·오방기는 `userId + 날짜 + 상품 + 카테고리 (+ 질문 해시)`, 꿈해몽은 `userId + 날짜 + 꿈 내용 정규화 해시` ([F05](features/F05-saju.md), [F06](features/F06-tarot.md), [F07](features/F07-dolyeong.md), [F08](features/F08-dream.md))
- ✅ 한 번 나온 결과는 저장하고, 다시 열면 저장본을 보여준다 (LLM 재호출 없음)
- ✅ 난수 생성은 **서버**에서 (클라이언트 조작 방지)

## 타로집
| 항목 | 내용 | 상태 |
|---|---|---|
| 덱 | 메이저 아르카나 22장 | ✅ D-053 |
| 정·역방향 | 사용. 역방향 확률 25% | ✅ D-053 |
| 카드 그림 | 코드로 만든 SVG 22장 (D-030) | ✅ |
| 질문 카테고리 | 연애 / 재물 / 직장 / 오늘 | ✅ |

### 스프레드
| 이름 | 장수 | 위치별 의미 | 가격 |
|---|---|---|---|
| 오늘의 한 장 | 1 | 오늘 | 무료 |
| 과거·현재·미래 | 3 | 과거: 지금까지의 흐름 / 현재: 지금의 상태 / 미래: 다가올 흐름 | 무료 |

- [ ] 카드별 정/역방향 의미표 22장 × 2 = 44개 (LLM `facts`용) — 콘텐츠 작성 필요

## 아기도령 (신점)
- ✅ 오방기 뽑기로 결과를 정한다 (D-031). 다섯 색 깃발 중 하나를 서버의 seed로 고른다
- [ ] 깃발 다섯 색과 색별 의미표 — 콘텐츠 작성 필요 (출처 확인. 길흉, 키워드, 조언 방향)
- ✅ 색마다 기본 의미 1개 + 카테고리별(연애·재물·직장·건강·기타) 한 줄 조언을 의미표에 둔다
- ✅ 한 번에 깃발 하나만 뽑는다 (D-054)
- ✅ 연출: 아기도령이 말아 쥔 깃발을 내밀고 유저가 하나를 탭한다. **어느 위치에 어떤 색이 있는지는 서버 seed로 이미 정해져 있다** (탭은 연출일 뿐 결과를 바꾸지 않음)
- ✅ 사주 데이터는 쓰지 않는다 (사주집과 겹치지 않게)

## 꿈해몽 (D-009)
- ✅ 입력은 자유 서술만 (D-021)
- ✅ 꿈 내용은 300자 이하 (D-027)
- ✅ 흐름: 꿈 내용 입력 → 1차 필터(코드) → 상징 추출(Haiku) → 꿈 사전 조회(코드) → LLM 해석 ([F08](features/F08-dream.md))
- ✅ 상징 추출은 Haiku가 하되 **꿈 사전에 있는 상징 ID 중에서만** 고른다. 상징의 의미는 꿈 사전(코드)에서 가져온다 (D-028, [04 §6](04-llm-spec.md#6-분류-호출-자유질문--꿈-내용))
- [ ] 꿈 사전 테이블 (상징 ID, 이름, 동의어, 길흉, 의미 키워드) — 콘텐츠 작성 필요. MVP 목표 150개
- ✅ 사전에 없는 상징만 있으면 차감 없이 "조금 더 자세히 얘기해 줘" 안내 ([F08](features/F08-dream.md))
- ✅ 같은 날 같은 꿈(공백·문장부호를 정리한 해시)이면 저장된 결과를 연다
- ✅ 자유 서술이라 [04 §6](04-llm-spec.md#6-분류-호출-자유질문--꿈-내용)의 필터와 안전 규칙을 그대로 적용
- ✅ 꿈해몽은 무료다 (D-057)

## 자유질문 (무료, D-057)
- ✅ 타로 3장(`tarot_three`)과 아기도령(`obanggi`)에 붙일 수 있다. 질문을 붙이면 카테고리는 분류 결과로 정한다 (D-056) ([04 §4](04-llm-spec.md#4-상품과-결과-길이-d-043-보통))
- ✅ 흐름: 질문 입력 → 필터 → 카테고리 분류 → 코드가 점괘/카드 결정 → LLM 해석 ([F09](features/F09-free-question.md))
- ✅ 필터와 안전 규칙은 [04-llm-spec.md](04-llm-spec.md#6-분류-호출-자유질문--꿈-내용)
