# 05. 캐릭터 시스템

상태: 🟡 초안

## 확정
- ✅ 2등신 귀여운 스타일 (D-004)
- ✅ 성별과 나이에 맞는 캐릭터가 기본으로 정해진다
- ✅ 종족·머리·옷·머리 장식 등을 꾸밀 수 있다 (D-098, [F17](features/F17-avatar-style.md))

## 2. 기본 캐릭터 매칭
✅ 4구간 × 성별 2 = 기본 아바타 8종 (D-017)

| 나이대 | 여 | 남 |
|---|---|---|
| 10대 (만 14~19세) | ✅ 댕기머리 + 통 원피스 (분홍) | ✅ 짧은머리 + 저고리·바지 (하늘·파랑) |
| 20대 | ✅ 긴머리 + 원피스 (보라) | ✅ 짧은머리 + 저고리 (연두·초록) |
| 30대 | ✅ 쪽머리 + 원피스 (청록) | ✅ 짧은머리 + 저고리 (회색) + 갓 |
| 40대 이상 | ✅ 쪽머리 + 비녀 + 원피스 (자주) | ✅ 짧은머리 + 저고리 (베이지·갈색) + 갓 |
- ✅ 나이대 차이는 머리 모양·옷 색·장식으로 낸다. 체형은 같다
- ✅ 이 기본 모습은 꾸미기(§3) 7칸의 기본 값으로 다시 쓴다. 꾸미기를 안 한 사람은 이 모습 그대로 ([F17](features/F17-avatar-style.md))
- [ ] 생일이 지나 나이대가 바뀌면 캐릭터도 바뀌는지 ⬜ (꾸미기를 저장한 사람은 바뀌지 않는다)

## 3. 꾸미기 파츠
✅ 캐릭터 꾸미기 [F17](features/F17-avatar-style.md) (D-098). 모두 무료, 성별과 상관없이 고른다.

| 칸 | 고를 것 | 기본 제공 | 유료 |
|---|---|---|---|
| 종족 | 사람, 고양이, 강아지, 토끼, 여우, 곰 (귀·꼬리·코·주둥이, 얼굴·손 털 색) | ✅ | ⬜ |
| 머리 | 짧은머리, 단발, 긴머리, 댕기머리, 쪽머리, 양갈래, 묶은머리, 뽀글머리, 상투, 없음 | ✅ | ⬜ |
| 머리색 | 기본(나이대), 검정, 갈색, 밤색, 금발, 빨강, 분홍, 파랑, 은발 | ✅ | ⬜ |
| 옷 | 저고리·바지, 치마저고리, 원피스 (D-086), 후드티, 도포 | ✅ | ⬜ |
| 옷 색 | 기본(성별·나이대 팔레트) + 9색. 색마다 주색·옅은 색·포인트 색 묶음 | ✅ | ⬜ |
| 머리 장식 | 없음, 리본, 꽃, 갓, 비녀, 족두리, 털모자 | ✅ | ⬜ |
| 피부 | 사람 4톤 / 동물은 종족마다 털 4색 | ✅ | ⬜ |
| 장신구·손 | 노리개, 부채 | ⬜ | ⬜ |

- ✅ 파츠 결합 방식: 뼈대 하나(몸·머리·팔·다리·눈)에 코드로 만든 공유 지오메트리를 붙이고 버텍스 컬러로 뼈마다 합친다 (`mergeRig`). 텍스처는 쓰지 않는다
- ✅ 데이터 형식: 7칸을 `.`으로 이은 코드 `species.hair.outfit.color.acc.hairColor.tone` (예: `cat.bob.dress.pink.ribbon.auto.0`). 외모 문자열은 `성별:나이대[:코드]`. 모르는 값이 섞이면 기본 모습
- ✅ 한도: 어떤 조합도 3,000 삼각형 이하, 합친 메시 수는 기본 모습보다 늘지 않는다 (07 §3)
