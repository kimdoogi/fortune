# 05. 캐릭터 시스템

상태: 🟡 초안

## 확정
- ✅ 2등신 귀여운 스타일 (D-004)
- ✅ 성별과 나이에 맞는 캐릭터가 기본으로 정해진다

## 1. 프로필 입력 화면
| 항목 | 형식 | 필수 | 검증 | 상태 |
|---|---|---|---|---|
| 닉네임 | 텍스트 | ✅ | 2~10자, 금칙어 | ✅ 마을·LLM에 쓰이는 유일한 이름 |
| 이름 | — | — | — | ✅ 받지 않음 (D-051) |
| 생년월일 | 날짜 + 양력/음력 + 윤달 | ✅ | [02](02-saju-rules.md#1-입력) 범위 | ✅ |
| 태어난 시간 | 시·분 / 12지시 / 모름 | ✅ | 서머타임으로 없는 시각은 오류 | ✅ |
| 성별 | 남 / 여 | ✅ | 둘 중 하나 | ✅ D-052 |

- ✅ 만 14세 미만은 이용 차단 (D-016). 생년월일 입력 단계에서 막는다. 안내: "만 14세 이상부터 이용할 수 있어요"
- [ ] 마을에서 다른 유저에게 **실명과 생년월일은 절대 보이지 않는다**

## 2. 기본 캐릭터 매칭
✅ 4구간 × 성별 2 = 기본 아바타 8종 (D-017)

| 나이대 | 여 | 남 |
|---|---|---|
| 10대 (만 14~19세) | ⬜ 외형 설명 | ⬜ |
| 20대 | ⬜ | ⬜ |
| 30대 | ⬜ | ⬜ |
| 40대 이상 | ⬜ | ⬜ |
- [ ] 나이대별 차이 표현 방식 ⬜ (머리 모양, 옷, 체형 크기 등)
- [ ] 생일이 지나 나이대가 바뀌면 캐릭터도 바뀌는지 ⬜

## 3. 꾸미기 파츠
| 슬롯 | 예시 | 기본 제공 | 유료 |
|---|---|---|---|
| 머리 | 갓, 댕기, 비녀 | ⬜ | ⬜ |
| 상의 | 저고리 (남성). 여성은 원피스 (D-086) | ⬜ | ⬜ |
| 하의 | 치마, 바지 | ⬜ | ⬜ |
| 장신구 | 노리개 | ⬜ | ⬜ |
| 손 | 부채 | ⬜ | ⬜ |

- [ ] 파츠 결합 방식 ⬜ (뼈대 공유 + 메쉬 교체 / 텍스처 교체)
- [ ] 파츠 데이터 형식과 ID 규칙 ⬜
