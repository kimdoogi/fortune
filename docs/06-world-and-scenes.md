# 06. 월드 · 화면 구성

상태: 🟡 초안 — 구조와 조작 확정, 배치도와 연출은 미정

## 확정
- ✅ 점집 거리는 멀티플레이, 점집 내부는 개인 공간 (D-007)
- ✅ 걸어서 건물에 들어가면 화면이 바뀐다
- ✅ 첫 방문은 프로필 → 지도 → 거리. 다시 오면 지도부터 (D-046)
- ✅ **점집마다 거리가 따로 있다.** 다른 점집으로 가려면 지도로 돌아간다 (D-047)
- ✅ 지도는 2D 일러스트(SVG) (D-048)
- ✅ 이동은 탭한 곳으로 걸어가기 (D-049)

## 2. 지도와 거리 구조
- ✅ 지도에서 점집을 고르면 그 점집 거리의 입구에 선다
- ✅ 거리마다 멀티플레이 채널이 따로다 (`village:<shopId>:<n>`, [15 §4](15-infrastructure.md#4-멀티플레이))
- [ ] 거리별 크기와 배치도 ⬜ (그림 첨부). 거리 하나에 점집 건물 1채 + 꾸밈 요소
- [ ] 거리별 분위기 ⬜ ([08](08-art-assets.md#1-스타일-가이드))

## 3. 조작
- ✅ 이동: 땅을 탭하면 그 자리로 걸어간다. 문을 탭하면 문 앞까지 가서 "들어가기"를 묻는다 (D-049)
- ✅ 걷는 속도 2.0m/s, 0.5m 격자 + A* 경로 찾기 ([F03](features/F03-street.md))
- ✅ 카메라: 3인칭 고정 각도로 캐릭터를 따라감, 회전 없음
- ✅ 충돌: 건물·나무 같은 고정물만. 유저끼리는 통과

## 4. 화면 전환
- ✅ 거리 → 점집 내부: 문 열림 + 페이드. WebSocket 연결은 유지하고 `enter_shop`만 보낸다 ([F04](features/F04-shop-enter.md))
- ✅ 다른 유저에게는 "건물로 들어감"으로 보인다
- ✅ 내부 → 거리: 문 앞에 선다
- ✅ 거리 → 지도: 채널에서 나간다
- ✅ 페이드 0.6초씩 (어두워짐 + 밝아짐)

## 5. 멀티플레이 표시
- ✅ 채널 정원 30명 (D-011)
- ✅ 채널 배정: 정원이 안 찬 채널 자동 배정. 친구와 같은 채널은 MVP 이후
- ✅ 채팅은 정해진 문장 + 이모트만 (D-010)

| 정해진 문장 (10개) | | 이모트 (6개) |
|---|---|---|
| 안녕하세요! | 화이팅! | 인사 |
| 반가워요 :) | 고마워요 | 하트 |
| 점 보러 오셨어요? | 같이 가요 | 박수 |
| 여기 점 잘 봐요! | 잘 가요~ | 놀람 |
| 오늘 운세 좋았어요 | 좋은 하루 보내요 | 춤 |
| | | 꾸벅 (고개 숙여 인사) |
- ✅ 동기화: 목적지만 보내고 각 클라이언트가 경로를 재생 ([15 §4](15-infrastructure.md#4-멀티플레이))
- ✅ 신고·차단: 길게 눌러 "이 사람 안 보기" / "신고" ([F03](features/F03-street.md))
