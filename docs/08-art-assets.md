## 3. 제작 흐름
- ✅ Codex CLI로 코드를 작성해 3D 에셋을 만든다 (D-018)
- ✅ 3D는 three.js 코드로 런타임에 생성한다 (D-029). 모델 파일과 업로드 단계가 없다
- [ ] 2등신 캐릭터 구성 규칙 ⬜ (머리·몸통·팔다리 기본 도형과 비율, 뼈대 구조, 파츠 교체 지점)
- ✅ 2D 에셋(타로 카드, UI, 공유 카드)은 코드로 SVG를 만든다 (D-030)
- [ ] 3D 생성 코드는 `packages/models/`, 2D SVG 생성 스크립트는 `tools/assets/`에 둔다
- [ ] 파일 이름 규칙 ⬜
- [ ] 성능 한도 준수 확인 ([07](07-mobile-performance.md))
