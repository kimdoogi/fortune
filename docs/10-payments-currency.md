# 10. 결제 · 복채

상태: ⏸ **MVP 제외 (D-057).** MVP는 결제도 복채도 없다. 아래는 출시 후 유료화(M6)를 위한 설계로 남겨 둔다

## 확정
- ✅ **MVP에는 결제도 복채도 없다 (D-057, D-050 대체).** 아래 항목은 유료화 때 다시 검토한다
- ✅ MVP는 결제 없이 무료 출시. PG는 출시 후 붙인다 (D-019)
- ✅ 복채는 무료로 지급하고 점을 볼 때 차감한다 (D-019). 무료 기간에도 LLM 비용을 제한하는 장치다
- ✅ 자유질문은 복채를 추가로 차감한다 (D-006, D-020)

## 1. 복채 무료 지급 규칙 (MVP)
| 지급 조건 | 양 | 제한 | 상태 |
|---|---|---|---|
| 첫 방문 | 30냥 | 계정당 1회 | ✅ D-025 |
| 매일 출석 | 10냥 | 하루 1회 | ✅ D-025 |
| 결과 공유 | 5냥 | 하루 1회 | ✅ D-025 |
| 연속 출석 보너스 | 없음 (MVP 이후) | | ✅ |

- ✅ 보유 상한 100냥 (D-025). 지급 후 100을 넘으면 100까지만 지급하고 "복채 주머니가 가득 찼어요" 안내
- ✅ "하루"는 한국 시간 자정 기준
- ✅ 하루 최대 사용량은 따로 두지 않는다. 하루 지급이 최대 15냥이라 그 자체가 제한이다. LLM 호출은 사용자당 하루 30회 상한 ([F12](features/F12-coins.md))
- ✅ 익명 계정 반복 생성 대비: IP당 하루 5개, 넘으면 첫 방문 복채 없음 ([F14](features/F14-session.md))
- ✅ 원장에 `source`(free / paid)를 기록해 나중에 유료 충전분과 구분한다

## 2. 상품 가격 (복채)
| 상품 | 복채 | 상태 |
|---|---|---|
| 오늘의 운세 | 0 | ✅ |
| 타로 1장 | 0 | ✅ |
| 타로 3장 스프레드 | 10 | ✅ D-026 |
| 사주 정밀 풀이 | 30 | ✅ D-026 |
| 아기도령 신점 (오방기) | 10 | ✅ D-026 |
| 꿈해몽 | 10 (꿈 내용 처리 포함, 자유질문 추가 없음) | ✅ D-026 |
| 자유질문 추가 | +10 | ✅ D-026 |
| 꾸미기 파츠 | ⬜ | ⬜ |

- 출석 10냥이면 10냥짜리 점을 하루 1번 볼 수 있고, 사주 정밀은 사흘을 모아야 한다. Haiku 1회 원가가 약 3원이라 가격은 비용이 아니라 **이용 빈도를 조절하는 장치**다

## 3. 차감 규칙
- [ ] 복채는 **LLM 호출 전에 차감**하고, 실패하면 자동 환원한다 (원장에 `refund` 항목)
- [ ] 같은 요청이 두 번 처리되지 않도록 요청 ID로 중복을 막는다
- [ ] 잔액 확인과 차감은 하나의 트랜잭션
- [ ] 자유질문·꿈 내용이 필터에서 차단되면 차감하지 않는다

## 4. 유료화 (출시 후)
### 충전 묶음 (초안)
| 묶음 | 가격 | 보너스 |
|---|---|---|
| 30냥 | 3,300원 | — |
| 100냥 | 9,900원 | +10 |
| 300냥 | 27,000원 | +50 |

- [ ] PG사 ⬜ (토스페이먼츠 / 포트원)
- [ ] 결제수단 ⬜ (카드, 카카오페이, 네이버페이, 토스페이)
- [ ] 결제 완료는 **PG 웹훅/서버 검증으로만** 확정한다 (클라이언트 신호는 믿지 않음)
- [ ] 결제 전에 카카오 로그인이 필요한지 ⬜ (비회원 결제는 환불·분쟁 처리가 어려움)
- [ ] 구독 ⬜ (포함 내용, 가격, 사용 상한)
- [ ] 환불 정책, 디지털 콘텐츠 청약철회 제한 고지, 미성년자 결제 취소권 대응 ⬜
- [ ] 사업자 등록, 통신판매업 신고, 부가세 ⬜
