## M1. 기반
- ✅ 저장소: pnpm 모노레포, Biome, Vitest. 앱 4개 뼈대 완료 (2026-11-25)
  - `apps/api` (app Worker): Static Assets + `/api/*`, 개발용 사주 계산·풀이 경로, WebSocket 토큰 발급, 마을 연결 전달
  - `apps/reading`: Service Binding 전용(공개 주소 없음). 지금은 고정 응답(`LLM_MODE=fixture`), 실제 호출은 M2
  - `apps/realtime`: 마을 Durable Object (토큰 검사, 30명 상한, 메시지 크기·간격 제한)
  - `apps/web`: Vite + Preact + three.js
- ✅ `fortune-engine` 완료 (2026-11-25): 네 기둥, 음력 변환, 오행·십신·신강·용신·대운·세운·월운·일진·합충. 테스트 147건 통과
- ✅ 해석 데이터 초안: 사주, 타로 22장, 꿈 사전 150개, 오방기, 인사말, 금지 표현 목록 v1 (`packages/prompts`). 형식·금지 표현 테스트 통과, **사람 검수는 남음**
- ✅ 점집 거리 1개 + 2등신 캐릭터 탭 이동 (싱글): 점집 4곳 색 테마, 성별·나이대 8종 캐릭터, A* 길찾기, 문 앞 "들어가기". 375×812 화면에서 확인
- ✅ 아트 1차 다듬기 (2026-11-25, D-065): 밤하늘·달·먼 산, 처마가 들린 기와지붕 한옥, 석등·청사초롱 빛무리, 점집별 소품, 캐릭터 머리·한복·표정, 현판·한지 UI. 375×812에서 드로우콜 48, 삼각형 4.7만, 거리 생성 20ms 이하
- ✅ 배포 (2026-11-25): Worker 3개 배포, D1 `fortune-prod`(APAC)·KV 생성, 원격 마이그레이션, 비밀값 `WS_TOKEN_KEY`·`PII_KEY` 등록. 공개 주소는 app Worker 하나 (`https://fortune-app.dugiz94.workers.dev`, 도메인을 정하면 옮긴다). reading·realtime은 공개 주소 없음
- 🟡 AI Gateway 경로 확인 (D-066): 바인딩 → `default` 게이트웨이 → Anthropic 경로 동작 확인. **남은 것:** Anthropic 키 등록(BYOK 또는 reading secret), 대시보드에서 하루 $10 한도·"Require provider credentials" 켜기
- [ ] 목표 기기에서 [07](07-mobile-performance.md) 기준 충족 (30 FPS) — **실기기 필요**. 첫 화면 JS 30KB(gzip), three.js는 지도 뒤에 따로 불러온다
- [ ] F14 Turnstile: 위젯을 만들고 `TURNSTILE_SECRET`을 넣으면 켜진다. **IP당 하루 계정 제한은 테스트 기간이라 꺼 둠** (`ACCOUNTS_PER_IP="0"`, 2026-11-25). Turnstile을 켤 때 다시 5로 올린다

## M2. 점 보기
M1에서 남았던 F14(비회원 계정)·F02(프로필)·F01(지도)도 이번에 함께 만들었다.
- ✅ 비회원 계정·프로필·지도 (F14, F02, F01): 쿠키 세션, IP당 하루 5계정, 생년월일 AES-GCM 암호화, 만 14세 미만 차단, 캐릭터 미리보기, SVG 밤 마을 지도
- ✅ 점집 4개 내부 + 화면 전환 (F04): 점술가 4명(각 5,000 삼각형 이하), 내부 드로우콜 28~30·삼각형 3.3만 이하, 0.6초 페이드, 문 앞에서 내부를 미리 생성
- ✅ 점집별 풀이 화면 (F05~F08): 사주판, 타로 22장 SVG와 부채꼴 뽑기, 오방기 펼치기, 꿈 검사(개인정보·위기 안내), 한 글자씩 나오는 결과
- ✅ 결과 저장 / 다시 보기 (F10), 오늘의 운세 (F13, KV 저장·일간별 공유, Cron 미리 생성은 남음)
- ✅ reading Worker 실제 풀이 동작 (2026-11-25): 배포 서버에서 타로 풀이 확인 (응답 약 4.6초, 입력 352·출력 515 토큰, 캐시 쓰기 2,395). 지금은 Anthropic 직접 호출 (D-067), 게이트웨이 BYOK는 남음
- ✅ 나이대·성별 맞춤 풀이 (2026-11-25, D-069): 공통 규칙 v3. 배포 서버에서 10대 여·20대 남·30대 여·40대 이상 여 풀이와 20대 남 사주 정밀로 확인
- ✅ 콕 집어 말하기 (D-070, 공통 규칙 v4)와 이어 묻기 (F15, D-071): 배포 서버에서 타로 세 장 + 이어 묻기 3번 확인. 두 번째부터 앞 문맥 6,354~6,610토큰이 캐시에서 읽히고 새 입력은 4토큰, 4번째는 막힘
- ✅ 이어 묻기 오탐 수정과 시원한 말투 (2026-11-25, D-072, 이어 묻기 v3): 일상 질문 12개 모두 답함·폭력 질문만 차단. "연락 올까요?" → "네, 먼저 연락 와요", "언제쯤?" → "내년 봄이에요"
- ✅ 아기도령 신점 대화 (2026-11-25, D-073, F07 개정): 공수로 나이대×성별 고민을 먼저 맞히고 짧게 5번 주고받음. 배포 서버에서 10대 여·20대 남·30대 여·40대 이상 남 확인, 같은 날 재입장 시 대화 이어짐
- ✅ 아기도령 조언 위주로 (2026-11-25, D-074): 공수에 결론·할 일·조심할 것, 대화 답마다 할 일 또는 조심할 것, 5번째는 점괘 정리. 호칭(아/야)은 코드가 만들어 넣음. 배포 서버에서 5번 대화와 3명 비교 확인
- [ ] LLM 기준 샘플 평가 통과: 평가 도구 준비 완료 (`ANTHROPIC_API_KEY=… pnpm --filter @fortune/reading eval`, 해석 28·분류 5). 키가 있어야 돌릴 수 있다
- 정한 것 (api 구현 중): 진행 중인 같은 requestId는 429 `RATE_LIMITED`, LLM 실패도 하루 30회에 센다(04 §9), 오늘의 운세 행운의 색은 일간을 생하는 오행 색(일간별 공유라 용신을 모름)
