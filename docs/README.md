# 점집 메타버스 기획 문서

모바일 웹 three.js 메타버스. 지도에서 점집을 골라 2등신 캐릭터로 마을을 걸어 다니고(멀티플레이), 점집 안에 들어가면 혼자만의 공간에서 점을 본다.

**원칙: 이 문서에 적힌 것만 구현한다.** 문서에 없거나 모호한 부분은 코딩 전에 문서부터 고친다.

## 상태 표기

| 표기 | 뜻 |
|---|---|
| ✅ 결정됨 | 확정. 바꾸려면 [결정 기록](decisions/README.md)에 남긴다 |
| 🟡 초안 | 내용은 있으나 검토 필요 |
| ⬜ 미정 | 비어 있음. 채워야 구현 가능 |
