# F01. 지도 / 점집 선택

- 상태: ✅ 확정 (2026-11-24). 의미표 같은 콘텐츠는 별도로 채운다
- 관련 문서: [06](../06-world-and-scenes.md), [07](../07-mobile-performance.md), [08](../08-art-assets.md)
- 마일스톤: M1

## 목적
점집 네 곳을 한눈에 보여주고, 고른 점집의 거리로 보내는 출발점. 다시 방문한 사용자는 여기서 시작한다.

## 사용자 흐름
1. 화면에 2D 일러스트 지도(SVG)가 뜬다. 점집 4곳의 건물 그림과 이름이 보인다 (D-048)
2. 점집을 탭하면 아래에서 정보 카드가 올라온다: 점술가 얼굴, 이름, 한 줄 소개, 볼 수 있는 점
3. "가기"를 누르면 그 점집의 거리(F03)로 이동한다
4. 지도 위에는 늘 보이는 버튼: 내 캐릭터(프로필), 오늘의 운세(F13), 점 기록(F10)

## 입력
없음 (탭만).

## 출력
- 선택한 `shopId` (`saju` | `tarot` | `dolyeong` | `dream`) → F03으로 전달
- 지도에 있는 동안 고른 점집 거리의 3D 코드를 미리 불러온다

## 처리 규칙
- 지도는 SVG 하나. 3D 엔진 없이 뜬다 (첫 화면을 가볍게)
- 지도가 뜬 직후 three.js와 공통 모델 생성 코드를 백그라운드로 불러온다
- MVP의 모든 점은 무료이고 복채가 없다 (D-057). 화면에 가격·잔액을 표시하지 않는다

## 예외 상황
| 상황 | 처리 |
|---|---|
| WebGL을 지원하지 않는 기기 | "이 기기에서는 마을에 들어갈 수 없어요" 안내. 오늘의 운세·점 기록은 계속 쓸 수 있다. 2D로 점 보기는 MVP 이후 |
| 3D 코드 불러오기 실패 | "가기"를 눌렀을 때 다시 시도 버튼 |
| 프로필 없음 (첫 방문인데 F02를 건너뜀) | F02로 보낸다 |

## 완료 기준
- [ ] 목표 기기에서 첫 화면(지도)까지 [07](../07-mobile-performance.md#2-용량과-로딩) 용량·시간 한도 안
- [ ] 점집 4곳 탭 → 카드 → 가기 → 해당 거리로 이동
- [ ] 세로 화면에서 글자와 버튼이 잘리지 않는다 (가장 작은 기준: 360×640 CSS px)

- 지도에서 다른 유저 보기
