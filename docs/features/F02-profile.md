# F02. 프로필 입력 / 캐릭터 생성

- 상태: ✅ 확정 (2026-11-24). 의미표 같은 콘텐츠는 별도로 채운다
- 관련 문서: [02](../02-saju-rules.md), [05](../05-character-system.md), [09](../09-backend-data.md), [11](../11-legal-policy.md)
- 마일스톤: M1

## 목적
사주 계산에 필요한 정보를 받고, 성별·나이대에 맞는 2등신 캐릭터를 만들어 준다. 첫 방문 때 지도보다 먼저 나온다 (D-046).

## 사용자 흐름
1. 환영 화면: "점을 보려면 몇 가지만 알려주세요" + 개인정보 수집 동의
2. 한 화면에 한 항목씩 입력한다: 닉네임 → 생년월일 → 태어난 시간 → 성별
3. 입력이 끝나면 캐릭터 미리보기: 성별 × 나이대 기본 아바타가 등장해 인사한다
4. "이 모습으로 시작" → 저장 → 지도(F01)

## 입력
| 항목 | 타입 | 필수 | 검증 |
|---|---|---|---|
| 닉네임 | 텍스트 | ✅ | 2~10자, 금칙어 검사, 중복 허용 |
| 달력 | 양력 / 음력 | ✅ | |
| 생년월일 | 날짜 | ✅ | 1920-01-01 이후 (D-035), 실제로 있는 날짜, 음력이면 그 달의 일수 이내 |
| 윤달 | 체크 | 음력일 때 | 그 해에 그 윤달이 있어야 함 |
| 태어난 시간 | 시·분 / 12지시 / 모름 | ✅ | 서머타임 시작으로 없는 시각이면 다시 입력 (D-037) |
| 성별 | 남 / 여 | ✅ | 둘 중 하나 필수 (D-052). 안내 문구: "대운의 방향을 정하는 데 필요해요" |

## 출력
- `POST /api/profile` → 저장된 프로필, 계산된 사주 원국 요약(일간, 띠), 배정된 기본 아바타 ID
- 응답에 경고 플래그: `ambiguousTime`, `solarTermDay`(시간 모름일 때)

## 처리 규칙
- 나이 = 오늘 기준 만 나이. **만 14세 미만이면 저장하지 않고 이용 불가 안내** (D-016)
- 나이대: 10대(만 14~19) / 20대 / 30대 / 40대 이상 (D-017) → 기본 아바타 8종 중 하나
- 12지시를 고르면 그 시의 가운데 시각으로 계산한다 (예: 자시 → 한국 표준시 00:30, 축시 → 02:30)
- 음력 입력은 서버의 `fortune-engine`이 양력으로 바꾼다
- **이름은 받지 않는다** (D-051). 서비스 어디에도 쓰이지 않아 개인정보를 줄인다
- 프로필의 생년월일·출생 시각은 암호화해서 저장한다 ([09 §4](../09-backend-data.md#4-개인정보))
- 프로필을 고칠 수 있다. 고쳐도 이미 본 점 결과는 그대로 남는다 (결과에 당시 입력이 저장되어 있음)

## 예외 상황
| 상황 | 처리 |
|---|---|
| 만 14세 미만 | "만 14세 이상부터 이용할 수 있어요" 안내, 저장 안 함 |
| 1920년 이전 | 범위 안내 |
| 없는 날짜 (2월 30일, 음력 작은달 30일) | 입력 칸에서 바로 오류 |
| 그 해에 없는 윤달 | "그 해에는 윤N월이 없어요" |
| 서머타임 시작으로 없는 시각 | "그 시각은 서머타임으로 건너뛴 시간이에요. 다시 확인해 주세요" |
| 서머타임 종료로 두 번 있는 시각 | 저장은 하고 "앞쪽 시각으로 계산했어요" 안내 (D-038) |
| 저장 중 네트워크 오류 | 입력값을 기기에 임시 보관하고 다시 시도 |

## 완료 기준
- [ ] [02a](../02a-saju-test-cases.md)의 입력 오류 케이스(K-02, K-03, I-06, F-05)가 화면에서도 같은 안내로 막힌다
- [ ] 만 14세 미만 입력이 서버에 저장되지 않는다 (서버에서도 검사)
- [ ] 8종 아바타가 성별·나이대에 맞게 배정된다
- [ ] 개인정보 수집 동의 없이는 진행할 수 없다

## 하지 않는 것
- 태어난 장소 입력 (D-032)
- 이름 입력 (D-051)
- 꾸미기 파츠 선택 (MVP 이후. MVP는 기본 아바타 8종만)
