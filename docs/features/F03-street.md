# F03. 점집 거리 이동 / 멀티플레이

- 상태: ✅ 확정 (2026-11-24). 의미표 같은 콘텐츠는 별도로 채운다
- 관련 문서: [06](../06-world-and-scenes.md), [07](../07-mobile-performance.md), [15 §4](../15-infrastructure.md#4-멀티플레이)
- 마일스톤: M1 (혼자 이동), M3 (멀티플레이)

## 목적
고른 점집 앞 거리에서 내 캐릭터로 걸어 다니고, 같은 거리에 있는 다른 사람들과 인사를 나눈다. **점집마다 거리가 따로 있다** (D-047).

## 사용자 흐름
1. 지도에서 고른 점집의 거리에 도착한다. 내 캐릭터는 거리 입구에 선다
2. 땅을 탭하면 그 자리로 걸어간다 (D-049)
3. 다른 사람(최대 29명)이 닉네임과 함께 보인다
4. 하단 버튼으로 이모트와 정해진 문장을 보낸다 (D-010)
5. 점집 문을 탭하면 문 앞까지 걸어간 뒤 "들어가기"를 묻는다 → F04
6. 왼쪽 위 "지도"로 돌아간다

## 입력
| 항목 | 타입 | 검증 |
|---|---|---|
| 이동 목표 | 탭한 땅의 좌표 | 걸을 수 있는 영역 안 (아니면 가장 가까운 가능한 지점) |
| 이모트 | 이모트 ID | 목록에 있는 것만 |
| 정해진 문장 | 문장 ID | 목록에 있는 것만 ([06 §5](../06-world-and-scenes.md#5-멀티플레이-표시)) |

## 출력
- 화면: 거리 장면, 내 캐릭터, 다른 캐릭터, 말풍선, 이모트
- WebSocket 메시지 ([15 §4](../15-infrastructure.md#메시지-종류-초안)): `move`, `emote`, `chat`, `enter_shop`, `exit_shop`

## 처리 규칙
- **채널:** `village:<shopId>:<n>`. 정원 30명 (D-011). app Worker가 정원이 안 찬 채널을 배정한다
- **이동:** 탭 지점까지 경로를 찾는다. 거리마다 0.5m 간격의 걸을 수 있는 격자를 장면 생성 코드가 함께 만들고, A* 로 경로를 구한다. 서버에는 목적지만 보낸다. 다른 클라이언트는 같은 격자로 같은 경로를 계산해 재생한다
- **속도:** 걷는 속도 3.0m/s 고정 (D-092, 처음엔 2.0). 서버는 직전 목적지에서 직선거리 ÷ 3.0초보다 빨리 온 새 목적지를 무시한다
- **입장 시:** `snapshot`으로 현재 사람과 위치를 받아 배치한다
- **메시지 빈도 제한:** 이모트·문장 2초에 1번, 이동 0.3초에 1번. 넘는 메시지는 서버가 버린다
- **혼자 모드:** WebSocket 연결이 안 되면 다른 사람 없이 거리를 계속 쓸 수 있다 (점 보기는 가능)
- **신고·차단:** 다른 캐릭터를 길게 누르면 메뉴가 뜬다
  - "이 사람 안 보기": 내 화면에서만 숨긴다. 기기에 저장해 다음 접속에도 유지
  - "신고": 사유(부적절한 닉네임 / 따라다니며 방해 / 기타)를 고르면 `reports`에 저장. 운영자가 확인 후 닉네임 초기화 또는 접속 제한

## 예외 상황
| 상황 | 처리 |
|---|---|
| WebSocket 끊김 | 자동 재연결 (1, 2, 4, 8초 간격, 최대 5번) → 실패하면 혼자 모드 + 안내 |
| 채널이 꽉 참 | 다른 채널로 배정 |
| 사람이 많아 느려짐 | 멀리 있는 캐릭터부터 숨긴다 ([07 §4](../07-mobile-performance.md#4-런타임-생성과-최적화)) |
| 백그라운드로 갔다 돌아옴 | 다시 연결하고 `snapshot`을 새로 받는다 |

## 완료 기준
- [ ] 탭 이동이 목표 기기에서 [07](../07-mobile-performance.md) FPS 한도 안
- [ ] 두 기기에서 서로의 이동·이모트·문장이 1초 안에 보인다
- [ ] 30명째 이후 입장자는 새 채널로 간다
- [ ] 연결을 끊어도 거리에서 점집에 들어갈 수 있다
- [ ] 실명·생년월일이 다른 사람에게 보이지 않는다 (닉네임만)

## 하지 않는 것
- 자유 채팅 (D-010)
- 다른 점집 거리로 바로 걸어가기 (지도를 거쳐야 함, D-047)
- 친구와 같은 채널 들어가기 (MVP 이후)
