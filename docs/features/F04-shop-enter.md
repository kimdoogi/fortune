# F04. 점집 입장 / 화면 전환

- 상태: ✅ 확정 (2026-11-24). 의미표 같은 콘텐츠는 별도로 채운다
- 관련 문서: [06 §4](../06-world-and-scenes.md#4-화면-전환), [04a](../04a-persona-prompts.md)
- 마일스톤: M2

## 목적
거리에서 점집 안으로 들어가 점술가와 마주 앉는다. 안은 나만의 공간이다 (D-007).

## 사용자 흐름
1. 거리(F03)에서 문을 탭 → 문 앞까지 걸어감 → "들어가기" 버튼
2. 문이 열리며 화면이 어두워졌다 밝아진다 (페이드 0.6초씩)
3. 점집 내부. 점술가가 첫인사를 한다 (미리 써둔 대사, LLM 아님)
4. 볼 수 있는 점 목록이 뜬다 (모두 무료, D-057)
5. 점을 고르면 해당 기능으로 간다 (F05~F08)
6. "나가기"를 누르면 거리의 문 앞으로 돌아간다

## 입력
없음 (탭만).

## 출력
- WebSocket `enter_shop` / `exit_shop` (다른 사람에게 "건물에 들어감"으로 보임)
- 점 목록: 상품 ID, 이름, 오늘 이미 본 결과가 있는지

## 처리 규칙
- 점집 내부는 서버 동기화 없음. WebSocket 연결은 유지한다 ([15 §4](../15-infrastructure.md#4-멀티플레이))
- 전환 중에 내부 장면을 생성한다. 생성이 끝나기 전에는 페이드를 유지한다
- 거리 장면의 리소스는 내부에 있는 동안 메모리에 남겨 둔다 (빠른 복귀). 브라우저가 메모리 부족을 알리거나 내부에 5분 넘게 있으면 해제하고, 나올 때 다시 만든다 ([07 §5](../07-mobile-performance.md#5-메모리))
- 점 목록에서 "오늘 이미 본 점"은 "다시 보기"로 표시하고, 누르면 저장된 결과를 연다 (LLM 호출 없음)

| 점집 | 점 목록 |
|---|---|
| 사주집 | 오늘의 운세, 사주 정밀 |
| 타로집 | 오늘의 한 장, 세 장 스프레드 (질문 붙이기 가능) |
| 아기도령 | 신점 (대화, F07) |
| 꿈해몽 | 꿈해몽 |

## 예외 상황
| 상황 | 처리 |
|---|---|
| 내부 장면 생성 실패 | 거리로 돌아가고 다시 시도 안내 |
| 들어가는 중 WebSocket 끊김 | 무시하고 들어간다 (내부는 연결이 필요 없음) |

## 완료 기준
- [ ] "들어가기" → 내부 첫인사까지 목표 기기에서 2초 이내
- [ ] 다른 사람 화면에서 내가 건물로 사라지고, 나오면 다시 나타난다
- [ ] 나가면 문 앞에 선다

## 하지 않는 것
- 점집 안에서 다른 사람 보기
- 점술가와 자유 대화 (풀이에 이어 3번까지 묻는 것은 [F15](F15-followup.md))
