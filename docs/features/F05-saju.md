# F05. 사주 풀이 (사주 정밀)

- 상태: ✅ 확정 (2026-11-24). 의미표 같은 콘텐츠는 별도로 채운다
- 관련 문서: [02](../02-saju-rules.md), [04 §4](../04-llm-spec.md#4-상품과-결과-길이-d-043-보통), [04a](../04a-persona-prompts.md#사주집--청운-선생), [10](../10-payments-currency.md)
- 마일스톤: M2
- 상품: `saju_full` — 무료, 전체 섹션 공개 (D-057)

## 목적
내 사주 원국과 올해 흐름을 청운 선생이 풀어 준다. MVP에서는 모든 섹션을 바로 보여준다.

## 사용자 흐름
1. 사주집 안에서 "사주 정밀" 선택
2. 청운 선생이 사주판(8글자)을 펼치는 연출. 이 동안 서버가 계산하고 LLM을 부른다
3. 사주판 + 요약(`overall`)이 한 글자씩 나온다
4. 아래로 내리면 나머지 섹션 8개가 이어서 나온다 (섹션마다 접고 펼 수 있음)
5. 결과는 점 기록(F10)에 남는다

## 입력
- 요청: `POST /api/readings { shop: "saju", product: "saju_full", requestId }`
- 프로필은 서버가 가진 것을 쓴다 (화면에서 다시 받지 않음)

## 출력
- 사주판: 네 기둥(시간 모름이면 세 기둥), 오행 분포 그래프, 일간
- 결과 JSON ([04 §5](../04-llm-spec.md#5-출력-형식-llm--코드)) 전체
- 섹션 제목(코드가 붙임): 총평, 성격, 오행, 용신, 대운, 올해, 연애, 재물, 일

## 처리 규칙
- **seed / 저장 키:** 프로필 버전 + 연도. 같은 해에 다시 보면 저장본을 연다. 프로필을 고치면 새 풀이
- 계산: [02 §5](../02-saju-rules.md#5-계산-범위-mvp-d-040) 전부 + 대운(현재) + 세운(올해)
- LLM 입력: [04 §3-2](../04-llm-spec.md#3-2-사주-shop-saju). `facts`는 해석 데이터 표에서 ([02 §7](../02-saju-rules.md#7-해석-데이터-테이블))
- 한 번 호출로 전 섹션을 생성해 저장한다. 나중에 유료화할 때 일부 섹션만 잠글 수 있게 섹션 키 구조는 유지한다 (D-045 구조, 잠금은 MVP 이후)
- 시간 모름이면 사주판에 시주 자리를 비워 두고 "시간을 모르면 시주 없이 보오" 표시
- 결과 하단에 "재미로 보는 풀이예요"를 코드가 붙인다

## 예외 상황
| 상황 | 처리 |
|---|---|
| LLM 실패 ([04 §9](../04-llm-spec.md#9-실패-처리)) | 대체 문장. 저장 안 함 (다음에 새로 생성) |
| 하루 상한(30회) 도달 | "오늘은 점을 많이 봤소. 내일 다시 오시오" (사용자당 하루 30회 상한 (D-057)) |
| 같은 요청이 두 번 감 | `requestId`로 한 번만 생성 |
| 프로필 없음 | F02로 |
