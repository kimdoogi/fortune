# F06. 타로 풀이

- 상태: ✅ 확정 (2026-11-24). 의미표 같은 콘텐츠는 별도로 채운다
- 관련 문서: [03 타로집](../03-tarot-and-other-readings.md#타로집), [04 §3-3](../04-llm-spec.md#3-3-타로-shop-tarot), [04a](../04a-persona-prompts.md#타로집--달님-언니)
- 마일스톤: M2
- 상품: `tarot_one`, `tarot_three` (질문 붙이기 가능). 모두 무료 (D-057)

## 목적
달님 언니가 카드를 펼쳐 주고, 내가 고른 카드를 풀어 준다.

## 사용자 흐름
1. 타로집 안에서 "오늘의 한 장" 또는 "세 장 스프레드" 선택
2. 질문 카테고리 선택: 연애 / 재물 / 직장 / 오늘
3. (세 장) 질문을 붙일지 묻는다 → 붙이면 F09
4. 카드가 부채꼴로 펼쳐진다. 1장 또는 3장을 탭해 고른다
5. 고른 카드가 뒤집히고 결과가 한 글자씩 나온다

## 입력
- `POST /api/readings { shop: "tarot", product, category, questionId?, requestId }`
- 카드를 고르는 탭은 서버로 보내지 않는다 (연출)

## 출력
- 카드: 이름, 정/역방향, 위치(과거·현재·미래)
- 결과 JSON: `tarot_one` → `card`, `message` / `tarot_three` → `past`, `present`, `future`, `advice`

## 처리 규칙
- **seed:** `userId + 날짜(한국 시간) + product + category (+ 질문 해시)`. 같은 날 같은 조건이면 같은 카드, 저장본을 연다
- **카드 결정은 서버.** seed로 섞은 덱에서 위에서부터 뽑는다. 화면의 어느 카드를 탭하든 결과는 같다 ([03](../03-tarot-and-other-readings.md#공통-결과-고정-규칙))
- 덱은 **메이저 아르카나 22장**, 역방향 확률은 **25%** (D-053)
- `facts` = 카드 의미표(22장 × 정·역 = 44개)의 해당 의미 (콘텐츠 작성 필요)
- 모든 해석 호출은 사용자당 하루 30회 상한 (D-057)에 포함된다

## 예외 상황
| 상황 | 처리 |
|---|---|
| 하루 상한(30회) 도달 | 달님 언니 말투로 "오늘은 카드가 쉬고 싶대요. 내일 또 봐요" |
| LLM 실패 | 대체 문장. 카드도 보여주지 않는다. 다시 보면 seed가 같아 같은 카드가 나온다 |
| 질문이 차단됨 (F09) | 질문 없는 스프레드로 할지 묻는다 |

## 완료 기준
- [ ] 같은 날 같은 카테고리로 다시 보면 같은 카드와 같은 풀이 (LLM 재호출 없음)
- [ ] 다른 카드를 탭해도 결과가 같다

## 하지 않는 것
- 켈틱 크로스 등 다른 스프레드
- 카드를 직접 섞기
