# F07. 아기도령 신점 (대화)

- 상태: ✅ 확정 (2026-11-25, D-073 — 오방기 뽑기(D-031, D-054)를 대체. D-087로 진짜 신점 순서와 쌀점을 넣음)
- 관련 문서: [03 아기도령](../03-tarot-and-other-readings.md#아기도령-신점), [04 §4](../04-llm-spec.md#4-상품과-결과-길이-d-043-보통), [04 §13](../04-llm-spec.md#13-이어-묻기-호출-followup), [04a 아기도령](../04a-persona-prompts.md#아기도령)
- 마일스톤: M2
- 상품: `sinjeom`. 무료 (D-057). 예전 `obanggi`는 점 목록에서 빠지고, 이미 본 결과는 기록에서 그대로 열린다

## 목적
진짜 신점집에 온 느낌. 앉자마자 아기도령이 방울을 흔들더니 "**너 요즘 ○○ 때문에 마음 쓰이지?!**" 하고 먼저 맞힌다. 그다음 짧게 짧게 주고받는다.

## 사용자 흐름 (진짜 신점 순서, D-087)
조사한 신점 진행: 무당이 먼저 나이(띠)를 묻고 → 제상의 쌀을 집어 던져 쌀알 수·홀짝으로 길흉을 보고(쌀점) → 신령이 무당 입을 빌려 신의 처지에서 말하는 **공수**를 내린다. 공수는 문제·서운한 점을 먼저 짚고, 문답을 거쳐, **복을 약속하며("도와주마")** 끝난다 (한국민족문화대백과 「공수」·「쌀점」)
1. **띠 묻기:** 들어가면 아기도령이 "○○야, 몇 살이야? …아, ○띠구나!" (코드가 프로필의 띠로 만든 문장, LLM 없음)
2. **방울·쌀 던지기:** "할아버지한테 물어볼게!" 방울을 흔들고 쌀을 던진다. 놋 쟁반에 쌀알이 떨어지고 개수가 뜬다 — "일곱 알! 제일 좋은 수야!" / "넷… 짝수네, 조심하라는 거야" (등급별 문장은 코드)
3. **공수:** 3~4줄이 한 줄씩. ① 신령(할아버지)이 하는 말로 시작해 쌀점 결과를 짚고 ② 요즘 속 끓인 일·서운한 일을 먼저 콕 집고("너 요즘 ○○ 때문에 속상했지?!") ③ 결론(된다·언제)과 할 일
4. **문답:** 빠른 답 칩 — "그럼 어떻게 해?", "연애는?", "돈은?", "일은?", "조심할 건?" — 또는 직접 입력(60자). 답은 2~3문장, 결론부터, 할 일 또는 조심할 것 하나 이상. 신령의 말투로 "할아버지가 그러는데" 같은 말을 섞는다
5. **처방과 복 약속 (마지막 5번째 답):** 오늘의 처방 — 할 일 하나, 조심할 것 하나, 좋은 때(달) — 그리고 "내가 도와줄게!"로 복을 약속하고, 복채 농담("복채는 됐어, 웃으면 돼!")으로 끝낸다. 처방에 물건 사기·부적·굿은 없다 (04 §7 금지)
6. 사용자 말 **5번**까지. 다 쓰면 대화가 닫힌다
7. 대화는 점 기록(F10)에 남는다. 같은 날 다시 오면 지난 대화를 보여 주고 남은 횟수만큼 이어서 한다

## 입력
- 시작: `POST /api/readings { shop: "dolyeong", product: "sinjeom", requestId }`
- 대화: `POST /api/readings/:id/followups { question, requestId }` (F15와 같은 API, 대화 한도만 5)

## 출력
- 시작: `ReadingResult` — `output.sections.gongsu`(공수, 줄바꿈으로 2~4줄), `summary`(기록 목록 한 줄), `advice`(오늘의 한마디), `followups[]`, `followupsLeft`
- 대화: F15 `FollowupResponse`

## 처리 규칙
- **seed / 저장 키:** `sinjeom:<날짜>` — 하루 한 번. 같은 날이면 저장본(대화 포함)을 연다
- **쌀점과 숨은 점괘 (D-087):** 서버가 seed로 쌀알 수(1~10)를 정하고, 등급에 맞는 오방기 색을 고른다 ([03 아기도령](../03-tarot-and-other-readings.md#아기도령-신점)). 쌀알 수·등급·풀이 기준과 색의 뜻이 `facts`로 들어간다. 결과의 `visual.rice = { count, grade }`로 화면이 쟁반의 쌀알을 그린다. 손님의 띠도 `facts`에 넣는다 (연간 지지에서 나온 값, D-051 범위 안)
- **고민 고르기:** 공수에서 짚을 고민은 LLM이 나이대×성별 흔한 고민 목록(04a 공통 규칙)에서 하나 고른다. 사주 데이터는 쓰지 않는다 (사주집과 겹치지 않게)
- 공수 1번 + 대화 최대 5번 = 최대 6번 호출. 모두 하루 30회 상한에 포함
- 대화 호출은 F15와 같은 구조: 원래 공수·앞선 대화를 저장된 문자열 그대로 이어 보내 캐시를 타고, `{ risk, answer }`로 위험 검사를 같이 한다. 위험·차단 처리도 F15와 같다
- 대화의 아기도령 말은 110자 안팎, 반말, 짧은 문장. 숨은 점괘의 뜻 안에서만 말한다
- 대화 메시지에는 몇 번째인지 함께 보낸다 `{"question", "turn", "of"}` — 마지막 답을 정리로 만들기 위해. 순번은 매번 같은 값이라 캐시가 깨지지 않는다
- 결과 하단 "재미로 보는 풀이예요" 고지는 코드가 붙인다

## 예외 상황
| 상황 | 처리 |
|---|---|
| 하루 상한(30회) | "오늘은 방울이 지쳤어! 내일 또 와!" |
| LLM 실패 | 대체 문장 ("으앙, 방울 소리가 안 들려! 이따 다시 와!"), 다시 시도 |
| 위험 글 | 위기 안내 (F15) |
| 대화 5번 다 씀 | 입력 칸 대신 "오늘은 여기까지! 또 와!" |

## 완료 기준
- [ ] 들어가서 첫마디까지 4초 안 (공수 생성 포함)
- [ ] 공수가 나이대·성별에 맞는 고민을 짚는다 (10대·20대·30대·40대 이상 × 남녀 확인)
- [ ] 같은 날 다시 들어오면 같은 대화가 이어진다 (LLM 재호출 없이 공수 재사용)
- [ ] 두 번째 대화부터 캐시 읽기가 0보다 크다

## 하지 않는 것
- 깃발 고르기 연출 (D-073으로 뺌)
- 하루 두 번 이상 신점
- 사주 데이터 쓰기
