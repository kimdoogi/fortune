# F07. 아기도령 오방기

- 상태: ✅ 확정 (2026-11-24). 의미표 같은 콘텐츠는 별도로 채운다
- 관련 문서: [03 아기도령](../03-tarot-and-other-readings.md#아기도령-신점), [04 §3-4](../04-llm-spec.md#3-4-아기도령-shop-dolyeong), [04a](../04a-persona-prompts.md#아기도령)
- 마일스톤: M2
- 상품: `obanggi` (질문 붙이기 가능). 무료 (D-057)

## 목적
아기도령이 말아 쥔 다섯 색 깃발 중 하나를 뽑고, 깃발의 뜻을 아이 말투로 들려준다 (D-031).

## 사용자 흐름
1. 아기도령 앞에 앉으면 방울을 흔들며 인사
2. 카테고리 선택: 연애 / 재물 / 직장 / 건강 / 기타
3. 질문을 붙일지 묻는다 → 붙이면 F09
4. 아기도령이 깃발 다섯 개를 말아서 내민다. 하나를 탭한다
5. 깃발이 펼쳐지고 결과가 한 글자씩 나온다

## 입력
- `POST /api/readings { shop: "dolyeong", product: "obanggi", category, questionId?, requestId }`

## 출력
- 뽑힌 깃발 색
- 결과 JSON: `flag`, `message`, `advice`

## 처리 규칙
- **seed:** `userId + 날짜 + category (+ 질문 해시)`
- **깃발 색은 서버가 seed로 정한다.** 어느 깃발을 탭하든 같은 색이 나온다
- 다섯 색과 색별 의미·등급은 [03](../03-tarot-and-other-readings.md#아기도령-신점)의 오방기 의미표를 따른다 (콘텐츠 작성 필요)
- 한 번에 깃발 하나만 뽑는다 (D-054)
- 카테고리가 `건강`이면 해석 입력에 `caution`을 넣는다 ([04 §6](../04-llm-spec.md#6-분류-호출-자유질문--꿈-내용))
- 해석 호출은 사용자당 하루 30회 상한 (D-057)에 포함된다

## 예외 상황
F06과 같다.

## 완료 기준
- [ ] 같은 날 같은 조건이면 같은 깃발·같은 풀이
- [ ] 건강 카테고리 결과에 진단·단정 표현이 없다 (평가 샘플로 확인)

## 하지 않는 것
- 여러 번 뽑기 (D-054)
- 쌀점, 방울점 등 다른 신점
