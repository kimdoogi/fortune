# F08. 꿈해몽

- 상태: ✅ 확정 (2026-11-24). 의미표 같은 콘텐츠는 별도로 채운다
- 관련 문서: [03 꿈해몽](../03-tarot-and-other-readings.md#꿈해몽-d-009), [04 §6](../04-llm-spec.md#6-분류-호출-자유질문--꿈-내용), [04a](../04a-persona-prompts.md#꿈해몽--몽실-할매)
- 마일스톤: M2
- 상품: `dream`. 무료 (D-057)

## 목적
꿈 이야기를 쓰면 몽실 할매가 꿈 사전의 상징 뜻으로 풀어 준다.

## 사용자 흐름
1. 몽실 할매가 차를 내주며 "꿈 얘기 해 봐"
2. 꿈 내용을 쓴다 (300자 이하, 글자 수 표시)
3. "할매한테 들려주기" → 서버가 먼저 검사한다
4. 통과하면 해석한다. 찻잔에서 김이 오르는 연출 뒤 결과가 한 글자씩 나온다. 찾은 상징이 아이콘으로 위에 뜬다

## 입력
| 항목 | 타입 | 검증 |
|---|---|---|
| 꿈 내용 | 텍스트 | 300자 이하 (D-027), 비어 있으면 안 됨 |

- 검사: `POST /api/readings/check { shop: "dream", text }` → `{ checkId, ok, reason?, symbols? }`
- 해석: `POST /api/readings { shop: "dream", product: "dream", checkId, requestId }`

## 출력
- 찾은 상징 목록 (이름, 아이콘)
- 결과 JSON: `symbols`, `meaning`, `advice`

## 처리 규칙
1. 1차 필터(코드): 길이, 금칙어, 개인정보 패턴
2. 분류 호출(Haiku): 위험 여부 + 상징 ID (꿈 사전 enum) ([04 §6](../04-llm-spec.md#6-분류-호출-자유질문--꿈-내용))
3. 코드가 상징 ID를 꿈 사전과 대조 → 의미를 `symbols`에 붙인다
4. **짧은 꿈도 푼다 (D-077):** "뱀 꿈", "이빨 빠짐"처럼 한두 마디여도 상징을 고른다. 사전에 똑같은 게 없으면 뜻·장면이 가장 가까운 상징 1~3개를 고른다. 상징이 하나도 없을 때(꿈 내용이 전혀 없는 "ㅋㅋ", "몰라" 같은 글)만 "조금 더 자세히 얘기해 줘" 안내
5. 통과하면 해석 호출. 짧은 꿈은 상징의 뜻과 나이대·성별 상황으로 장면을 채워 풀이하고, 더 써 달라고 하지 않는다. 분류·해석 호출 모두 사용자당 하루 30회 상한 (D-057)에 포함
- **seed / 저장 키:** `userId + 날짜 + 꿈 내용 정규화 해시` (공백·문장부호 정리). 같은 날 같은 꿈이면 저장본
- 검사 결과(`checkId`)는 10분 동안 유효. 지나면 다시 검사

## 예외 상황
| 상황 | 처리 |
|---|---|
| 위험 내용 (`self_harm`) | 점을 보지 않고 위기 안내 화면 ([04a](../04a-persona-prompts.md#위기-안내-코드가-직접-표시)) |
| 차단 (`sexual`, `violence`, `other`) | 할매 말투 안내 |
| 개인정보가 들어 있음 | "전화번호 같은 건 빼고 써 줘" |
| 해석 실패 | 대체 문장 |

## 완료 기준
- [ ] 차단되는 글은 해석 호출로 넘어가지 않는다
- [ ] 결과에 나온 상징이 모두 꿈 사전에 있는 것이다
- [ ] 같은 날 같은 꿈을 다시 쓰면 같은 결과 (LLM 재호출 없음)
- [ ] 위험 글을 넣으면 위기 안내가 뜬다 (평가 샘플)

## 하지 않는 것
- 꿈 상징 직접 고르기 (D-021)
- 지난 꿈들을 모아 분석하기
