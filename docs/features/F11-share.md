# F11. 결과 공유 카드

- 상태: ✅ 확정 (2026-11-24). 의미표 같은 콘텐츠는 별도로 채운다
- 관련 문서: [08](../08-art-assets.md)
- 마일스톤: M4

## 목적
결과를 인스타 스토리 크기 이미지로 만들어 공유하고, 친구가 들어오게 한다. MVP에는 공유 보상이 없다 (D-057).

## 사용자 흐름
1. 결과 화면(S5)의 "공유하기"
2. 미리보기: 9:16 카드 이미지
3. "공유" → 휴대폰 공유 창 (카카오톡, 인스타그램 등) / 공유를 못 쓰면 "이미지 저장"

## 입력
- 결과 ID (화면에 이미 있는 데이터로 만든다)

## 출력
- PNG 이미지 1080×1920
- 공유 텍스트: "{점집 이름}에서 점 봤어요 ✨ {서비스 주소}"

## 처리 규칙
- **카드는 기기에서 만든다.** SVG 템플릿(D-030)에 값을 채워 캔버스로 PNG를 만든다. 서버 호출 없음
- 카드에 들어가는 것: 점집 캐릭터, 점집 이름, `summary`, `greeting` 또는 `advice` 중 하나, 행운의 색(있으면), 날짜, 서비스 주소
- **카드에 넣지 않는 것:** 생년월일, 사주판, 잠긴 섹션 내용, 질문·꿈 원문 (사적인 내용)
- 공유는 Web Share API(파일 공유). 지원하지 않으면 이미지 다운로드
- 템플릿은 점집별 1종 (4종)

## 예외 상황
| 상황 | 처리 |
|---|---|
| 공유 창 취소 | 아무 일도 하지 않는다 |
| 이미지 생성 실패 (메모리 부족 등) | 해상도를 낮춰 다시 만든다 |

## 완료 기준
- [ ] iOS Safari, 삼성 인터넷, Android Chrome에서 공유 또는 저장이 된다
- [ ] 카드에 개인정보·잠긴 내용이 없다

## 하지 않는 것
- 공유 링크로 결과 페이지 열기 (결과는 이미지로만)
- 공유·친구 초대 보상 (MVP 이후)
