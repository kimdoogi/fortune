# F13. 오늘의 운세

- 상태: ✅ 확정 (2026-11-24). 의미표 같은 콘텐츠는 별도로 채운다
- 관련 문서: [04 §8](../04-llm-spec.md#8-오늘의-운세-일괄-생성), [02 §5-6](../02-saju-rules.md#5-6-세운--월운--일진)
- 마일스톤: M2
- 상품: `daily`. 무료

## 목적
매일 들어올 이유. 지도에서 바로 오늘 하루 운세를 청운 선생 말투로 본다.

## 사용자 흐름
1. 지도(F01)의 "오늘의 운세" 버튼, 또는 사주집 안의 메뉴
2. 오늘 날짜와 일진, 결과(`overall`, `tip`)가 한 글자씩 나온다
3. 아래에 "사주집 가기", "공유하기"(F11)

## 입력
- `GET /api/daily` (프로필의 일간을 서버가 씀)

## 출력
- `{ date, iljin, dayMaster, result: { greeting, summary, sections: { overall, tip }, advice, luckyColor } }`

## 처리 규칙
- 결과는 **일간(10개) × 오늘 일진**으로 정해진다. 사용자마다 따로 부르지 않는다
- 전날 12:00 Cron이 다음 날 10건을 Batch로 만들어 KV(`daily:<날짜>:<일간>`)에 저장한다 ([04 §8](../04-llm-spec.md#8-오늘의-운세-일괄-생성))
- KV에 없으면 그 일간 한 건만 실시간으로 만들어 저장한 뒤 보여준다. 동시에 여러 명이 요청해도 한 번만 만들도록 D1에 `daily_gen(date, stem)` 행을 먼저 넣은 요청만 생성하고, 나머지는 1초 간격으로 최대 10초까지 KV를 다시 확인한다
- "오늘"은 한국 시간 자정 기준
- 점 기록(F10)에 남기지 않는다 (매일 바뀌는 내용이라)

## 예외 상황
| 상황 | 처리 |
|---|---|
| 프로필 없음 | F02로 |
| 실시간 생성도 실패 | 대체 문장 |

## 완료 기준
- [ ] 같은 일간인 두 사용자는 같은 날 같은 운세를 본다
- [ ] 자정이 지나면 새 날짜 운세로 바뀐다
- [ ] 하루 LLM 호출이 10건 안팎이다 (실시간 대체 포함)

## 하지 않는 것
- 일지·원국과 일진의 합충까지 반영한 개인화 (MVP 이후)
- 알림(푸시)
