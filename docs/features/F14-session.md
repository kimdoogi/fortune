# F14. 비회원 계정 생성 / 유지

- 상태: ✅ 확정 (2026-11-24). 의미표 같은 콘텐츠는 별도로 채운다
- 관련 문서: [09 §1](../09-backend-data.md#1-계정), [15 §8](../15-infrastructure.md#8-보안)
- 마일스톤: M1

## 목적
가입 없이 바로 시작하게 하고, 같은 기기에서 다시 오면 내 캐릭터·점 기록이 그대로 있게 한다 (D-015).

## 사용자 흐름
1. 처음 접속 → 화면 뒤에서 Turnstile 확인 → 익명 계정 생성
2. F02(프로필)로
3. 다시 접속하면 저장된 기기 토큰으로 바로 지도(F01)

## 입력
- Turnstile 토큰 (사용자 입력 없음)

## 출력
- `POST /api/session` → HttpOnly·Secure·SameSite 쿠키로 기기 토큰 발급
- 응답: `{ userId, hasProfile, todayCallsLeft }`

## 처리 규칙
- 기기 토큰 수명 1년, 접속할 때마다 1년으로 다시 연장
- 쿠키가 있으면 계정 생성 없이 그 계정을 쓴다
- **악용 방지** ([15 §8](../15-infrastructure.md#8-보안)): IP당 하루 계정 생성 5개. Turnstile 실패 시 생성 안 함. 6번째부터는 그날 새 계정을 만들지 않는다. 계정을 새로 만들어 하루 30회 상한을 피하는 것을 막기 위해서다
- 설정에 "내 정보 삭제": 계정, 프로필, 점 기록을 모두 지운다 (되돌릴 수 없음 안내 후)

## 예외 상황
| 상황 | 처리 |
|---|---|
| 쿠키 차단·시크릿 모드 | 매번 새 계정이 된다는 안내 |
| 브라우저 데이터 삭제 | 복구 불가. 처음 화면에 "브라우저 데이터를 지우면 기록이 사라져요" 안내 |
| Turnstile 실패 | 다시 시도. 계속 실패하면 안내 |

## 완료 기준
- [ ] 같은 기기·브라우저로 다시 오면 같은 계정
- [ ] 한 IP에서 한도 이상 계정을 만들 수 없다
- [ ] "내 정보 삭제" 후 DB에 그 사용자의 개인정보가 남지 않는다
- [ ] 쿠키는 JavaScript에서 읽을 수 없다 (HttpOnly)

## 하지 않는 것
- 카카오 로그인 (M6, D-019)
- 여러 기기에서 같은 계정 쓰기
