# F16. 같이 보기 (둘이 같이 — 궁합·관계 타로·둘의 신점·두 사람 꿈풀이)

- 상태: ✅ 확정 (2026-11-25, D-089 궁합 → D-090 지도에서 시작·점집마다 같이 보는 점)
- 관련 문서: [02 §5-9 궁합 계산](../02-saju-rules.md#5-9-궁합-d-089), [03](../03-tarot-and-other-readings.md), [04 §4](../04-llm-spec.md#4-상품과-결과-길이-d-043-보통), [04a 상품별 지시](../04a-persona-prompts.md#상품별-지시), [06 §5](../06-world-and-scenes.md#5-멀티플레이-표시), [09 §3](../09-backend-data.md#3-api-목록-초안), [15 §4](../15-infrastructure.md#4-멀티플레이)
- 마일스톤: M3 (멀티플레이를 먼저 둘만의 방으로 연다)
- 무료. 하루 30회 상한에는 **풀이를 만든 사람 1회**만 센다

## 목적
친구·연인·가족에게 링크를 보내 **같이** 점집 거리를 돌아다닌다. 지도에서 방장이 고른 점집으로 둘이 함께 이동해 서로 걷는 모습을 보고, 나란히 앉아 그 점집의 "같이 보는 점"을 함께 듣는다.

## 같이 보는 점 (점집마다 하나)
| 점집 | 상품 | 내용 |
|---|---|---|
| 사주집 | `gunghap` 궁합 | 두 사람 사주로 점수·잘 맞는 점·부딪히는 점 (02 §5-9) |
| 타로집 | `tarot_pair` 관계 타로 | 카드 3장: "○○ 님의 마음", "○○ 님의 마음", "두 사람의 앞날" |
| 아기도령 | `sinjeom_pair` 둘의 신점 | 쌀을 한 번 던져(쌀점) 두 사람 사이를 공수로 |
| 꿈해몽 | `dream_pair` 두 사람 꿈풀이 | 각자 간밤 꿈을 쓰면 할매가 두 꿈을 이어서 푼다 |
- 궁합·관계 타로·둘의 신점은 먼저 **관계**(연인·썸·친구·가족·동료)를 누구든 고르면 바로 풀이를 만든다. 고른 것은 상대 화면에도 보인다
- 꿈풀이는 둘 다 꿈을 써야 풀이를 만든다. 먼저 쓴 사람은 "○○ 님 꿈을 기다리는 중"
- 결과는 두 사람 화면에 같이 뜨고, 각자 기록(F10)에 남는다
- **이어 묻기(F15)는 같이 본다 (D-091):** 누가 물어도 질문과 답이 두 사람 화면에 함께 뜬다(상대 질문엔 "○○ 님의 질문"). 묻는 동안 상대 화면엔 "○○ 님이 물어보는 중…". 한도는 사람마다 3번

## 사용자 흐름
1. **초대 (방장):** 지도 아래 "같이 보기" → 동의 안내("두 사람의 띠·타고난 기운, 풀이와 더 물어본 질문이 서로에게 보여요. 생년월일과 태어난 시간은 보이지 않아요") → 초대 링크 → 공유(휴대폰 공유 창, 안 되면 복사) → "지도에서 기다리기"
2. **링크 열기 (손님):** `https://jumjip.app/?g=<코드>` → 처음이면 프로필(F02) → "○○님이 같이 보자고 불렀어요" + 같은 동의 → "같이 들어가기"
3. **같이 보는 지도:** 둘 다 지도에 있다. 위에 "○○ 님과 함께" 표시. **방장**이 점집을 누르고 "○○ 님과 같이 가기"를 누르면 **둘 다 그 점집 골목으로** 이동한다. 손님은 점집을 고를 수 없고 "○○ 님이 고르는 중"
4. **같이 걷기:** 서로 걷는 모습, 머리 위 닉네임. 둘 다 문 앞이면 "같이 들어가기" (누가 눌러도 둘 다)
5. **점집 안:** 나란히 앉아(왼쪽 = 방장) 그 점집의 같이 보는 점을 본다
6. **지도로:** 방장이 골목·점집에서 "지도"를 누르면 둘 다 같이 보는 지도로 돌아온다. 손님의 "나가기"는 같이 보기를 끝낸다(방장에게 "○○ 님이 나갔어요")
7. **끝내기:** 같이 보는 지도의 "같이 보기 끝내기" → 평소 지도로

## 입력
- 초대: `POST /api/pair/invites { consent: true }` → `{ code, url, expiresAt }` · 보기 `GET /api/pair/invites/:code` · 참여 `POST /api/pair/invites/:code/join { consent: true }`
- 이어 묻기: 평소와 같은 `POST /api/readings/:id/followups`. 같이 본 풀이면 서버가 상대 기록에도 같은 문답을 넣는다
- 실시간 방 토큰: `GET /api/ws-token?room=pair:<code>` (방장·손님만. 토큰에 역할 `host`·`guest`)
- 풀이: `POST /api/pair/:code/readings { product, relation, requestId }` (`gunghap`·`tarot_pair`·`sinjeom_pair`)
- 꿈: `POST /api/pair/:code/dream { text }` → 내 꿈 검사(F08과 같은 개인정보·위기 검사, 상징 고르기) 후 저장. 둘 다 내면 그 요청이 풀이를 만든다
- 내 결과: `GET /api/pair/:code/result?product=` (방에 `result_ready`가 오면 부른다)
- 예전 경로 `/api/gunghap/invites/...`도 같은 처리로 받는다 (D-089에서 배포한 것)

## 출력
- `ReadingResult`. visual: 궁합은 궁합 판, 관계 타로는 타로 세 장(자리 이름이 두 사람), 둘의 신점은 쌀점 쟁반, 꿈풀이는 두 꿈과 상징
- 섹션: 궁합 `overall`·`chemistry`·`strengths`·`friction`·`tips` / 관계 타로 `hearts`·`future`·`advice` / 둘의 신점 `gongsu` / 꿈풀이 `dreams`·`meaning`·`advice`

## 처리 규칙
- **초대 코드:** 10자 무작위(헷갈리는 글자 뺀 영숫자). 만든 뒤 30분 안에 참여 없으면 만료, 참여 뒤 3시간. 손님 한 명. 자기 초대에는 참여할 수 없다
- **결과 고정:** 초대 하나에 상품마다 풀이 하나. 궁합 `gunghap:<code>`, 나머지 `pair:<code>:<product>`. 두 사람 기록에 한 줄씩(같은 내용)
- **카드·쌀점:** 서버 seed(`pair:<code>:<product>`)로 정한다. 관계 타로의 카테고리는 관계로 정한다(연인·썸 → 연애, 동료 → 직장, 친구·가족 → 오늘)
- **LLM 입력:** 두 사람 닉네임·성별·나이대와 계산된 결과만 (D-051). 꿈풀이는 두 사람이 쓴 꿈 글과 고른 상징
- **실시간 방:** `pair:<code>` DO, 정원 2. 이동은 목적지만. 방 메시지: `move`·`emote`·`chat`·`travel`(방장만, 점집 또는 지도)·`go_inside`, 서버 → `traveled`·`went_inside`·`picked`·`submitted`·`result_ready`·`result_failed`·`asking`·`asked`(이어 묻기, D-091). 방은 마지막 `travel`을 기억해 나중에 들어온 사람도 같은 곳으로 보낸다
- **연결 유지:** 같이 보는 동안(지도·골목·점집 안) 연결 하나를 유지한다
- 결과 하단 "재미로 보는 풀이예요"는 코드가 붙인다

## 예외 상황
| 상황 | 처리 |
|---|---|
| 초대 만료·없는 코드 | "초대가 끝났소. 친구에게 새 링크를 받아 주시오" + 지도 가기 |
| 이미 다른 사람이 참여 | "이미 다른 분이 같이 보고 있소" |
| 프로필 없음 (손님) | 프로필 만들기(F02) 뒤 초대 화면으로 돌아온다 |
| 상대가 나감 | "○○ 님이 나갔어요". 같은 링크로 다시 들어오면 이어진다(유효 시간 안) |
| 실시간 연결 끊김 | 1·2·4·8·8초 간격으로 5번 다시 연결 |
| 꿈 글에 개인정보·위기 신호 | 그 사람에게만 F08 안내. 상대에게는 "○○ 님이 꿈을 다시 쓰는 중" |
| LLM 실패 | 대체 문장, 다시 시도 (04 §9). 둘 다에게 알린다 |
| 하루 상한 | 고른 사람에게 상한 안내. 상대가 대신 고를 수 있다 |

## 완료 기준
- [ ] 지도에서 초대 → 손님이 링크로 들어오면 둘 다 같이 보는 지도
- [ ] 방장이 점집을 고르면 손님도 0.5초 안에 같은 골목으로 이동
- [ ] 네 점집 모두 같이 들어가 같이 보는 점을 보고, 결과가 둘 다에게 뜬다
- [ ] 같은 초대·같은 상품으로 다시 보면 LLM을 다시 부르지 않는다
- [ ] 점집 안 드로우콜·삼각형 한도(07) 안

## 하지 않는 것
- 세 명 이상 같이 보기
- 둘만의 방에서 자유 채팅 (정해진 문장·이모트만)
- 같이 보기 중 혼자 보는 점 (끝내고 평소 지도에서 본다)
