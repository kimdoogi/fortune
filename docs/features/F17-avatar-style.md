# F17. 캐릭터 꾸미기

- 상태: ✅ 확정 (2026-11-25, D-098)
- 관련 문서: [05 §3 꾸미기 파츠](../05-character-system.md#3-꾸미기-파츠), [F02](F02-profile.md), [F03](F03-street.md), [F16](F16-gunghap.md), [07 §3](../07-mobile-performance.md), [09 §2](../09-backend-data.md)
- 마일스톤: M1 (무료. 유료 파츠는 나중에)

## 목적
프로필의 성별·나이대로 정해지던 모습에 내가 고른 꾸미기를 더한다. 사람 말고 동물이 될 수도 있고, 머리 모양·머리색·옷·옷 색·머리 장식·피부(털) 색을 바꾼다. 거리, 점집 안, 같이 보기 상대 화면 어디서나 같은 모습으로 보인다.

## 사용자 흐름
1. **처음 만들 때:** F02 마지막 "반가워요" 화면에 "꾸미기" 버튼 → 꾸미기 화면 → "이 모습으로" → 다시 반가워요 화면 → "이 모습으로 시작"
2. **나중에:** 지도 → 내 캐릭터 → "꾸미기" (주소 `#/style`)
3. **꾸미기 화면(모바일 세로):** 위쪽 절반에 미리보기(빙글 돌며 숨쉬기, 누르면 손 흔들기), 아래에 칸 탭 **종족 · 머리 · 머리색 · 옷 · 옷 색 · 장식 · 피부**, 탭마다 고를 것 격자. 하나를 누르면 미리보기가 바로 바뀐다
4. "처음 모습으로"는 성별·나이대 기본 모습으로 되돌린다(저장 전까지는 화면에서만)
5. "저장"을 누르면 서버에 저장하고 내 캐릭터로 돌아간다. 저장하지 않고 뒤로 가면 바뀌지 않는다

## 고를 수 있는 것 (모두 무료)
| 칸 | ID | 보기 |
|---|---|---|
| 종족 `species` | `human` 사람, `cat` 고양이, `dog` 강아지, `rabbit` 토끼, `fox` 여우, `bear` 곰 | 동물은 귀·꼬리·코(강아지·여우·곰은 주둥이)가 붙고 얼굴·손이 털 색. 사람 귀는 숨긴다 |
| 머리 `hair` | `short` 짧은머리, `bob` 단발, `long` 긴머리, `braid` 댕기머리, `bun` 쪽머리, `pigtails` 양갈래, `ponytail` 묶은머리, `curly` 뽀글머리, `topknot` 상투, `none` 없음 | 동물도 머리를 얹을 수 있다. `none`이면 털만 |
| 머리색 `hairColor` | `auto` 기본, `black`, `brown`, `chestnut`, `blonde`, `red`, `pink`, `blue`, `silver` | `auto` = 나이대 기본 색 |
| 옷 `outfit` | `jeogori` 저고리·바지, `chima` 치마저고리, `dress` 원피스, `hoodie` 후드티, `dopo` 도포 | |
| 옷 색 `color` | `auto` 기본, `red`, `pink`, `yellow`, `green`, `sky`, `navy`, `purple`, `black`, `white` | 색 하나가 주색·옅은 색·포인트 색 묶음. `auto` = 성별·나이대 기본 팔레트 |
| 장식 `acc` | `none` 없음, `ribbon` 리본, `flower` 꽃, `gat` 갓, `binyeo` 비녀, `jokduri` 족두리, `beanie` 털모자 | 리본·털모자는 옷의 포인트 색 |
| 피부 `tone` | `0`~`3` | 사람은 피부 4톤, 동물은 종족마다 털 4색 |
- 성별·나이대와 상관없이 무엇이든 고를 수 있다

## 기본 모습 (꾸미기를 안 한 사람)
꾸미기 값이 없으면 지금까지와 똑같다. 꾸미기 화면은 이 값으로 시작한다.

| | 10대 | 20대 | 30대 | 40대 이상 |
|---|---|---|---|---|
| 여 | 사람·댕기머리·원피스 | 사람·긴머리·원피스 | 사람·쪽머리·원피스 | 사람·쪽머리·원피스·비녀 |
| 남 | 사람·짧은머리·저고리 | 사람·짧은머리·저고리 | 사람·짧은머리·저고리·갓 | 사람·짧은머리·저고리·갓 |
색은 모두 `auto`, 피부 `0`.

## 입력
- 저장: `PUT /api/profile/style { style: AvatarStyle | null }` → `ProfileView`. `null`이면 꾸미기를 지우고 기본 모습으로
- 처음 만들 때도 같은 경로 (프로필을 만든 뒤). `PUT /api/profile`은 꾸미기를 건드리지 않는다
- `AvatarStyle = { species, hair, outfit, color, acc, hairColor, tone }`. 서버는 zod로 위 표의 값만 받는다 (그 밖은 `INVALID_INPUT`)

## 출력
- `ProfileView.style: AvatarStyle | null` (꾸미기 안 했으면 `null`)
- `ProfileView.avatarId`: 꾸미기 안 했으면 예전과 같은 `성별:나이대`, 했으면 `성별:나이대:코드`
- **코드** = 7칸을 `.`으로 이은 것: `species.hair.outfit.color.acc.hairColor.tone` (예: `cat.bob.dress.pink.ribbon.auto.0`)
- 실시간 방 토큰 `a`도 같은 `성별:나이대[:코드]`. 예전 앱은 앞 두 칸만 읽으므로 그대로 동작한다

## 처리 규칙
- **저장:** D1 `profiles.style` (TEXT, 코드 문자열, 없으면 NULL). 마이그레이션 0006. `profile_version`은 올리지 않는다 (사주 seed가 바뀌지 않게)
- **읽기:** 저장된 코드를 풀다가 하나라도 모르는 값이면 꾸미기 없음(기본 모습)으로 본다. 앱도 같은 규칙으로 토큰의 코드를 푼다
- **그리기:** 꾸미기가 있으면 그 값으로, 없으면 위 표의 기본 값으로 같은 함수가 그린다. 파츠는 모두 코드로 만든 공유 지오메트리. 거리·점집 안·미리보기 모두 `mergeRig`로 뼈마다 합친다(거리도 합쳐서 캐릭터 하나 드로우콜이 약 34 → 12)
- **성능 한도 (07 §3):** 어떤 조합도 캐릭터 하나 3,000 삼각형 이하, 합친 뒤 메시 수는 기본 모습보다 늘지 않는다 (새 파츠는 이미 있는 뼈와 재질에 붙는다). 모든 종족×머리×옷×장식 조합을 테스트한다
- 미리보기는 렌더러 하나를 두고 캐릭터만 갈아 끼운다 (탭할 때마다 WebGL을 새로 만들지 않는다)

## 예외 상황
| 상황 | 처리 |
|---|---|
| 저장 중 네트워크 끊김 | "인터넷 연결을 확인해 주세요". 고른 것은 화면에 그대로 |
| 예전 값만 있는 사람 | 기본 모습 그대로 |
| 모르는 코드(앞으로 새 파츠가 생겨 예전 앱이 받음) | 기본 모습 |
| WebGL2 없음 | 미리보기 자리에 불빛만. 고르기·저장은 된다 |

## 완료 기준
- [x] 7칸을 고르면 미리보기가 바로 바뀌고, 저장하면 거리·점집 안·같이 보기 상대 화면에 같은 모습
- [x] 꾸미기 없는 사람은 예전과 같은 모습
- [x] 모든 조합 3,000 삼각형 이하, 합친 메시 수가 기본보다 늘지 않음 (테스트)

## 하지 않는 것
- 유료 파츠·복채로 사기 (05 §3 "유료" 칸은 나중에)
- 손에 드는 것(부채), 노리개, 체형 바꾸기
- 다른 사람에게 꾸미기 따라 하기
