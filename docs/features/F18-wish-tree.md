# F18. 당산나무 (소원 빌기)

- 상태: ✅ 확정 (2026-11-25, D-099)
- 관련 문서: [01 PRD](../01-product-prd.md), [06 §1 화면](../06-world-and-scenes.md), [09 §2·§3](../09-backend-data.md), [F01 지도](F01-map.md), [F03 거리](F03-street.md), [F16 같이 보기](F16-gunghap.md)
- 마일스톤: M3
- 무료. LLM을 부르지 않는다 (하루 30회 상한에 세지 않는다)

## 목적
마을 어귀 큰 당산나무에 소원을 적은 오색 천을 묶는다 (소원지·서낭당 전통). 점을 보지 않아도 매일 들러 돌 하나 올리고, 30일 뒤 "그 소원 어떻게 됐어?"로 다시 찾아오게 한다.

## 장소
- 지도의 다섯 번째 장소. 점집이 아니라 길 끝의 큰 당산나무와 그 아래 돌탑
- 거리 장면 하나(F03과 같은 방식): 흙길, 돌 등롱, 금줄 두른 큰 나무, 돌탑. 가지마다 최근 2주 동안 사람들이 묶은 천(최대 150장)이 바람에 흔들린다. 내 천은 조금 크고 밝게, 이뤄진 소원은 금빛
- 나무 앞까지 걸어가면 "소원 빌기"·"돌 올리기"

## 소원 빌기 (하루 한 번)
1. 소원 적기: 1~40자
2. 천 색 고르기 (오방색):

   | 색 | 뜻 |
   |---|---|
   | 빨강 | 사랑·인연 |
   | 노랑 | 돈·복 |
   | 파랑 | 일·시작 |
   | 하양 | 건강·평안 |
   | 초록 | 배움·성장 |
3. "묶기" → 그 색 천이 가지에 걸리며 빛나고, 나무의 덕담 한 줄(색마다 미리 써 둔 문장 중 하나, LLM 아님)
- 오늘 이미 묶었으면 "오늘 소원은 묶었어요"와 내가 묶은 천

## 돌 올리기 (하루 한 번)
- 누르면 돌탑 꼭대기에 돌 하나가 얹히고 "오늘 돌 ○개가 올라갔어요" (모든 사람 합계)

## 다른 사람 소원
- 처음에는 **비공개**: 남의 천은 색과 수만 보인다 ("오늘 소원 ○개가 걸렸어요"). 글은 본인(과 같이 묶은 사람)만 본다
- 공개·"같이 빌어 주기"는 나중에 (글 검사·신고가 필요하다)

## 돌아보기
- 묶은 지 30일이 지난 소원이 있으면 나무에 왔을 때 "30일 전에 묶은 소원: ○○ — 어떻게 됐어요?" → "이뤄졌어요"(천이 금빛) / "아직이에요"
- "내 소원" 목록에서도 언제든 "이뤄졌어요"를 누를 수 있다

## 같이 보기 (F16)
- 방장이 지도에서 당산나무를 고르면 둘이 같이 간다 (`travel` 장소에 `tree`)
- 소원을 묶을 때 "○○ 님과 같이 묶기"를 고르면 천 하나에 두 사람 이름. 상대의 "내 소원"에도 보이고, 상대 화면의 나무에도 바로 천이 걸린다 (방 메시지 `wished`). 하루 한 번은 묶은 사람만 센다

## 입력·출력
- `GET /api/wishes` → `WishBoard { today: { wish, stoned }, stonesToday, wishesToday, cloths[], mine[], due }`
- `POST /api/wishes { text, color, requestId, pairCode? }` → `{ wish, blessing, board }`
- `POST /api/wishes/stone` → `{ stonesToday }`
- `POST /api/wishes/:id/outcome { outcome: "yes" | "no" }`

## 처리 규칙
- 글 검사(코드): 1~40자, 개인정보 패턴·금칙어(F08과 같은 규칙) → 걸리면 안내하고 저장하지 않는다
- 위기 낱말(죽고 싶다 등)이 있으면 저장하지 않고 위기 안내(04a)
- 하루 = 한국 시간 날짜. 소원·돌 모두 사람마다 하루 한 번
- 천 목록은 최근 14일, 최신 150장 + 내 소원(이뤄진 것 포함)

## 예외 상황
| 상황 | 처리 |
|---|---|
| 오늘 이미 묶음 | "오늘 소원은 묶었어요. 내일 또 와요" |
| 글 검사에 걸림 | 그 이유 안내, 다시 쓰기 |
| 위기 낱말 | 위기 안내 화면 |
| 같이 묶기인데 상대가 나감 | 혼자 묶기로 저장 |

## 완료 기준
- [ ] 지도에서 당산나무로 가서 소원을 묶으면 천이 나무에 걸리고, 다시 들어와도 남아 있다
- [ ] 돌 올리기는 하루 한 번, 합계가 보인다
- [ ] 30일 지난 소원에 돌아보기를 묻고, "이뤄졌어요"면 금빛
- [ ] 같이 보기로 둘이 가서 같이 묶으면 두 사람 목록·나무에 다 보인다
- [ ] 장면 드로우콜·삼각형 한도(07) 안

## 하지 않는 것
- 남의 소원 글 보기 (지금은)
- 소원 이루어 준다는 말, 돈을 내는 기도 (11 정책: 불안·결제 유도 금지)
- 연등·풍등 행사 (나중에)
