# F19. 족집게집 — 나는 어떤 사람 (성격·기질 맞히기)

- 상태: ✅ 확정 (2026-11-26, D-100)
- 관련 문서: [02 §5](../02-saju-rules.md#5-계산-범위-mvp-d-040), [02 §7](../02-saju-rules.md#7-해석-데이터-테이블), [04 §3-6](../04-llm-spec.md#3-6-족집게집-shop-jokjipge), [04 §4](../04-llm-spec.md#4-상품과-결과-길이-d-043-보통), [04a 족집게 도사](../04a-persona-prompts.md#족집게집--족집게-도사), [06](../06-world-and-scenes.md), [08 §1](../08-art-assets.md#점집별-외관), [09](../09-backend-data.md)
- 마일스톤: M2
- 상품: `nature` "나는 어떤 사람" — 무료. 하루 30회 상한에 1회로 센다

## 목적
"내가 어떤 사람인지 맞혀 주는 점집". 다섯 번째 점집 **족집게집**에서 **족집게 도사**가 돋보기로 들여다보듯 내 기질을 콕콕 집어 말한다. 사주 정밀(F05)의 `personality` 한 섹션보다 깊게, 생활 장면 여섯 개로 나눠 "딱 나네" 싶게 맞힌다.

## 사용자 흐름
1. 지도에서 족집게집 → 족집게집 골목 → 문으로 들어간다 (F03·F04와 같음)
2. 도사 인사 → 점 목록에 "나는 어떤 사람" 하나
3. 누르면 도사가 돋보기를 들어 들여다보는 연출(1.5초쯤). 이 동안 서버가 사주 원국을 계산하고 LLM을 부른다. **따로 묻는 것은 없다** (사용자 선택: 사주만)
4. 결과: 요약 한 줄 + 기질 판(나의 기운·많은 기운·없는 기운) + 섹션 여섯 개가 차례로
5. 섹션마다 아래에 **"맞아요" / "아니에요"** 버튼. 누르면 그 자리에 표시만 남고(다시 누르면 지움, 다른 쪽을 누르면 바뀜) 대화는 이어지지 않는다
6. 결과 아래 이어 묻기(F15)는 다른 점과 같다 (3번)
7. 점 기록(F10)에 남고, 다시 열면 눌러 둔 표시도 그대로 보인다

## 입력
- 요청: `POST /api/readings { shop: "jokjipge", product: "nature", requestId }`
- 프로필은 서버가 가진 것을 쓴다
- 표시: `PUT /api/readings/:id/marks { section, mark }` — `section`은 이 상품의 섹션 키, `mark`는 `"yes" | "no" | null`(지우기). 응답은 그 풀이의 표시 전체 `{ marks: { [section]: "yes" | "no" } }`. LLM을 부르지 않고 하루 상한에 세지 않는다

## 출력
- visual: `{ shop: "jokjipge", nature: NatureBoard }`
  - 나의 기운(일간 글자·오행·음양), 오행 막대(나무·불·흙·쇠·물), 많은 기운·없는 기운(십신 무리를 쉬운 말로: 나·친구, 재주·표현, 돈·현실, 책임·규칙, 공부·생각), 시간 모름 여부
- 섹션 (보이는 순서): `surface` 겉으로 보이는 나 · `inner` 속마음 · `people` 사람들 사이에서 · `atWork` 일할 때 · `inLove` 연애할 때 · `stress` 스트레스 받을 때
- `ReadingResult.marks`: 눌러 둔 표시 (이 상품만, 없으면 빈 객체)

## 처리 규칙
- **seed / 저장 키:** `nature:v1:<프로필 버전>`. 연도가 들어가지 않는다(타고난 기질은 해마다 바뀌지 않음). 같은 프로필이면 언제 다시 봐도 저장본을 연다. 프로필을 고치면 새 풀이
- **계산은 코드:** 사주 원국(02 §5) — 일간, 오행 분포·과다·부족, 원국 십신, 신강·신약, 원국 합충. 대운·세운·월운은 쓰지 않는다
- **십신 무리 세기 (코드):** 원국 십신 자리(연간·연지·월간·월지·일지·시간·시지, 시간 모름이면 다섯 자리)를 다섯 무리로 센다 — 비겁(비견·겁재), 식상(식신·상관), 재성(편재·정재), 관성(편관·정관), 인성(편인·정인). 가장 많은 무리 하나(2자리 이상일 때, 같으면 월지 → 일지 → 월간 순으로 그 자리 무리 먼저)가 "많은 기운", 0자리인 무리 전부가 "없는 기운"
- **facts (해석 데이터 표, 02 §7):** 일간 성향(사주와 같은 문장) + **일간별 생활 장면 여섯 칸**(새 표 `nature.json`의 `dayMaster`) + 많은 기운·없는 기운의 버릇(`groups`) + 오행 과다·부족 + 신강·신약 + 원국 합충. LLM은 facts에 없는 기질을 지어내지 않는다
- 표는 명리 일반론으로 우리가 쓴다(AI 초안 → 사람 검수, 02 §7과 같음). 칸마다 "어떤 버릇·반응인지"를 짧게 적고 예문은 넣지 않는다 (D-097)
- 한 번 호출로 여섯 섹션을 다 쓴다 (출력 1천 자 안팎이라 나누지 않음)
- **표시(맞아요/아니에요)는 표시만:** `readings.marks_json`(마이그레이션 0008)에 섹션별 값으로 둔다. 이어 묻기 입력이나 LLM에는 넣지 않는다. 내 풀이에만 누를 수 있다
- 결과 하단 "재미로 보는 풀이예요"는 코드가 붙인다

## 같이 보기 (F16)
- 족집게집에는 같이 보는 점이 없다. 같이 보는 지도에서 족집게집은 흐리게 두고 누르면 "족집게집은 혼자 들어가는 곳이에요"를 보여준다. 방(`pair:<code>`)의 `travel`도 족집게집은 받지 않는다

## 예외 상황
| 상황 | 처리 |
|---|---|
| LLM 실패 ([04 §9](../04-llm-spec.md#9-실패-처리)) | 도사 말투 대체 문장. 저장 안 함 |
| 하루 상한(30회) 도달 | "오늘은 돋보기가 뜨거워졌네. 내일 다시 오게" |
| 같은 요청이 두 번 감 | `requestId`로 한 번만 생성 |
| 프로필 없음 | F02로 |
| 남의 풀이에 표시 | 404 |
| 다른 상품 풀이에 표시 / 없는 섹션 | 400 |

## 완료 기준
- [ ] 지도·골목·실내에서 족집게집에 들어가 "나는 어떤 사람"을 보고 여섯 섹션이 나온다
- [ ] 같은 프로필로 다시 보면 LLM을 부르지 않는다
- [ ] 맞아요/아니에요를 누르고 기록에서 다시 열면 그대로다
- [ ] 같이 보는 지도에서 족집게집을 고를 수 없다
- [ ] 거리·실내 드로우콜·삼각형 한도(07) 안

## 하지 않는 것
- 따로 묻는 질문(선택지) — 사용자가 "사주만"을 골랐다. 나중에 넣으면 seed 판을 올린다
- 맞아요/아니에요로 대화 이어 가기, 맞힌 개수 점수 (표시만)
- 같이 보는 점 (둘의 기질 비교는 궁합이 한다)
- 관상·손금 (사진을 받지 않는다)
