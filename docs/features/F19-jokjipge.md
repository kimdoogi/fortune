# F19. 족집게집 — 나는 어떤 사람 (60유형·잘 맞는 사람 찾기)

- 상태: ✅ 확정 (2026-11-26, D-100 → D-101 60유형·도감·유형 카드, 맞아요/아니에요 뺌)
- 관련 문서: [02 §5-10 유형과 맞음](../02-saju-rules.md#5-10-60유형과-맞음-d-101), [02 §7](../02-saju-rules.md#7-해석-데이터-테이블), [04 §3-6](../04-llm-spec.md#3-6-족집게집-shop-jokjipge), [04 §4](../04-llm-spec.md#4-상품과-결과-길이-d-043-보통), [04a 족집게 도사](../04a-persona-prompts.md#족집게집--족집게-도사), [06](../06-world-and-scenes.md), [08 §1](../08-art-assets.md#점집별-외관), [09](../09-backend-data.md)
- 마일스톤: M2
- 상품: `nature` "나는 어떤 사람" — 무료. 하루 30회 상한에 1회로 센다. 도감·유형 카드는 LLM을 부르지 않아 세지 않는다

## 목적
"내가 어떤 사람인지 맞혀 주고, 나와 잘 맞는 사람을 찾게 해 주는 점집". 다섯 번째 점집 **족집게집**에서 **족집게 도사**가 사람을 **60가지 유형**("다정한 강아지"처럼 형용사 + 귀여운 동물) 중 하나로 콕 집고, 생활 장면으로 맞힌 뒤, 잘 맞는 유형·안 맞는 유형을 알려 준다. 도감과 내 유형 카드 링크로 실제로 잘 맞는 사람을 찾아본다.

## 60유형
- **결과에 나온 세 가지로 정한다** ([02 §5-10](../02-saju-rules.md#5-10-60유형과-맞음-d-101)): 나의 기운(나무·불·흙·쇠·물) × 두드러진 기운(나·친구 / 재주·표현 / 돈·현실 / 책임·규칙 / 공부·생각 / 고른 편) × 기운 세기(센 편·여린 편) = 60. 셋 다 결과의 기질 판에 그대로 보인다
- 이름은 **형용사 + 귀여운 동물**: "다정한 강아지", "깔끔한 펭귄", "생각 깊은 부엉이". 형용사·색은 나의 기운, 동물은 두드러진 기운 × 세기 (12종). 그림은 코드로 그린 동물 얼굴(색 = 나의 기운)
- 한 줄 소개·키워드도 같은 두 재료로 코드가 잇는다 (`types.json`)
- **일주·간지 글자(갑자 등)는 화면에도 분류에도 쓰지 않는다.** 띠 이야기도 하지 않는다
- **유형끼리 맞음**: 점수 30~98, 등급 넷(찰떡·잘 맞음·맞춰 가면 괜찮음·부딪힘), 요인(나의 기운 상생·같음·상극, 센/여린 짝, 두드러진 기운의 닮음·채움·부딪힘)
- 잘 맞는 유형 3개 = 나를 뺀 59개 중 점수 높은 순, 안 맞는 유형 3개 = 낮은 순

## 사용자 흐름
1. 지도 → 족집게집 골목 → 문 → 도사 인사. 점 목록에 "나는 어떤 사람"과 그 아래 "60유형 도감"
2. "나는 어떤 사람" → 돋보기 연출 → 결과
   - 맨 위 **내 유형 카드**: 동물 얼굴, 유형 이름("다정한 강아지"), 한 줄 소개, 키워드
   - 기질 판(나의 기운·많은 기운·없는 기운·오행 막대)
   - 여섯 장면 + **잘 맞는 사람·안 맞는 사람** 섹션 (도사가 풀어 줌)
   - **잘 맞는 유형 3 / 안 맞는 유형 3** 칩. 누르면 도감의 그 유형으로
   - 버튼: "60유형 도감 보기", "내 유형 카드 보내기"
3. **도감** (`#/types`): 60칸(동물 12줄 × 나의 기운 5칸). 칸마다 동물 얼굴·이름과 나와의 맞음 등급 색(찰떡·잘 맞음은 등불색, 부딪힘은 붉은 점). 위에 내 유형. 칸을 누르면 그 유형의 이름·소개·키워드와 "나와는 ○○ (점수)", 이유 요인 문장
4. **내 유형 카드 보내기**: 휴대폰 공유 창(안 되면 복사)으로 `https://jumjip.app/?t=<코드>`
5. **카드 받기** (`?t=<코드>` → `#/card/<코드>`): "○○ 님은 [유형]"
   - 프로필이 없으면 "내 유형 알아보기" → 프로필(F02) → 카드로 돌아온다
   - 프로필이 있으면 내 유형과 **둘의 맞음**(등급·점수·이유)을 바로 보여 준다
   - 버튼: "족집게집 가 보기", "내 카드도 보내기"
   - 내 카드를 내가 열면 "내 유형 카드예요" + 보내기
6. 결과는 점 기록(F10)에 남는다. 이어 묻기(F15) 3번은 다른 점과 같다

## 입력
- 풀이: `POST /api/readings { shop: "jokjipge", product: "nature", requestId }`
- 도감: `GET /api/types/me` → `{ type, matches: TypeMatch[60] }` (60갑자 순서, 나 자신 포함). 프로필 필요
- 카드 만들기: `POST /api/type-cards` → `{ code, url }`. 한 사람에 카드 하나(다시 만들면 같은 코드)
- 카드 보기: `GET /api/type-cards/:code` → `{ nickname, type, mine, viewer: { type, match } | null }`. 로그인 세션만 있으면 되고, 프로필이 없으면 `viewer`가 null
- `TypeMatch = { type, score, label, factors: { kind, good }[] }`

## 출력
- visual: `{ shop: "jokjipge", nature: NatureBoard }` — 기질 판 + `type`(유형 id, 예 `fire-self-soft`), `best`·`worst`(각 3개, `{ type, score, label }`)
- 섹션 (보이는 순서): `surface` 겉으로 보이는 나 · `inner` 속마음 · `people` 사람들 사이에서 · `atWork` 일할 때 · `inLove` 연애할 때 · `stress` 스트레스 받을 때 · `match` 잘 맞는 사람·안 맞는 사람

## 처리 규칙
- **seed / 저장 키:** `nature:v2:<프로필 버전>` (v2: 60유형, D-101). 연도 없음. 예전 v1 풀이는 기록에 그대로 남고, 새로 보면 v2로 푼다. v1 결과 화면에는 유형 카드가 없다
- **계산은 코드:** 사주 원국(02 §5) — 일간, 오행 분포·과다·부족, 원국 십신 무리 세기, 신강·신약, 원국 합충 → 60유형과 59개와의 맞음
- **십신 무리 세기 (코드):** 원국 십신 자리를 다섯 무리로 센다 — 비겁·식상·재성·관성·인성. 가장 많은 무리 하나(2자리 이상, 같으면 월지 → 일지 → 월간 순)가 "많은 기운", 0자리인 무리 전부가 "없는 기운"
- **facts:** 일간 성향 + 일간별 생활 장면 여섯 칸(`nature.json`) + 유형 이름·소개·키워드(`types.json`, 02 §5-10) + 잘 맞는/안 맞는 유형 3개씩과 그 요인 + 많은/없는 기운 버릇 + 오행 과다·부족 + 신강·신약 + 원국 합충. LLM은 facts에 없는 기질·유형 뜻을 지어내지 않는다
- **카드 코드:** 10자 무작위(헷갈리는 글자 뺀 소문자·숫자, F16과 같은 꼴). 만료 없음. 카드에는 닉네임과 유형만 보인다(생년월일·태어난 시간·성별은 안 보임). 닉네임·유형은 볼 때 프로필에서 읽어 프로필을 고치면 바뀐다. 계정 삭제 때 지운다
- 결과 하단 "재미로 보는 풀이예요"는 코드가 붙인다. 도감·카드 화면에도 같은 고지

## 같이 보기 (F16)
- 족집게집에는 같이 보는 점이 없다. 같이 보는 지도에서 족집게집은 흐리게 두고 누르면 "족집게집은 혼자 들어가는 곳이에요". 방의 `travel`도 받지 않는다

## 예외 상황
| 상황 | 처리 |
|---|---|
| LLM 실패 ([04 §9](../04-llm-spec.md#9-실패-처리)) | 도사 말투 대체 문장. 저장 안 함 |
| 하루 상한(30회) 도달 | "오늘은 돋보기가 뜨거워졌네. 내일 다시 오게" |
| 같은 요청이 두 번 감 | `requestId`로 한 번만 생성 |
| 프로필 없음 (풀이·도감) | F02로 |
| 없는 카드 코드 / 카드 주인이 계정을 지움 | "이 카드는 찾을 수 없네. 친구에게 새 링크를 받아 주게" + 지도 가기 |
| 공유 창이 없거나 막힘 | 링크 복사 + "링크를 복사했어요" |

## 완료 기준
- [ ] 결과에 내 유형 카드, 일곱 섹션, 잘 맞는/안 맞는 유형 3개씩이 나온다
- [ ] 같은 프로필로 다시 보면 LLM을 부르지 않는다
- [ ] 도감 60칸이 나와의 등급 색으로 보이고, 누르면 이유가 나온다
- [ ] 카드 링크를 다른 기기(프로필 없음)에서 열면 프로필 → 카드로 돌아와 둘의 맞음이 보인다
- [ ] 같이 보는 지도에서 족집게집을 고를 수 없다
- [ ] 거리·실내 드로우콜·삼각형 한도(07) 안

## 하지 않는 것
- 따로 묻는 질문(선택지) — 사주만 (D-100)
- 맞아요/아니에요 표시 — D-101에서 뺐다. `readings.marks_json` 칸은 다음 배포에서 지운다
- 거리에서 다른 사람 머리 위에 맞음 표시, 모르는 사람 추천·매칭 (동의·안전 문제)
- 유형 카드로 상대 사주 전체 궁합 (그건 같이 보기 궁합 F16)
- 관상·손금 (사진을 받지 않는다)
